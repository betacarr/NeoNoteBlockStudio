## Optional local audio-analysis development runtime

The development audio assistant invokes separately installed Python packages from the project's isolated `.local/audio-runtime` environment. The runtime and model weights are not included in the application distribution. Demucs code is MIT-licensed; librosa is ISC-licensed; SoundFile is BSD-licensed; PyTorch and torchaudio retain their own license notices in that environment. See docs/audio-assist.md for the official sources, local setup and current implementation limits. Demucs pretrained weights must not be assumed to share the code license: the author's personal/research-use statement is tracked separately. Demucs is not the default enabled path. MVSep Mega 53 supports confirmed on-demand downloads and a local five-head-plus-residual trial; its separate MIT weight grant and semantic limits are recorded in docs/audio-model-license-review.md and docs/audio-model-effects.md.

## Default note block preview samples

The distribution includes 20 unmodified Ogg files from Mojang's official Minecraft resource service, pinned to Java Edition 26.3. Their original encoded bytes and relative amplitudes are retained without normalization or gain correction. The official version metadata, asset index, sound-event mappings and SHA-1/SHA-256 hashes are recorded and verified at build time. See third_party/minecraft-samples/manifest.json and NOTICE.md for provenance and rights boundaries. The sounds retain the rights of the respective rightsholders, including Mojang / Microsoft, and are not covered by NeoNBS's source license or an OpenNBS license. They are used for editor preview; matching local game resources remain necessary for version-specific native comparison.


MVSEP Mega inference uses MIT BS-RoFormer source from ZFTurbo/Music-Source-Separation-Training v1.0.21, commit ea7eb9c20ea0e3f94368a30fc1654b51cdd55789; upstream credits Phil Wang (lucidrains). Copyright notices and MIT terms are preserved in third_party/mega_roformer/LICENSE and the packaged inference module. Local runtime dependencies beartype 0.14.1 and rotary-embedding-torch 0.3.5 are installed separately. Model weights and configuration are downloaded on demand, never bundled.

The local-only real-music evaluation uses a CC BY 3.0 excerpt of Slow Motion Dream, Steven M Bryant (c)2011, ft CSoul, Alex Beroza and Robert Siekawitch, from sigsep/spleeter-musdb audio_example.mp3. Audio and its separation derivatives are not bundled. Source attribution and changes are recorded in docs/audio-model-effects.md and the local listening folder.

The optional workspace-only fast Mega CPU runtime uses official PyTorch 2.8.0+cpu and fsspec 2025.9.0, retaining their installed license notices; it is not bundled. Local reference-based evaluations use explicitly CC0 recordings from Meta Open Sound, Karoryfer Samples (Big Little Bass, Big Rusty Drums, Hadzi-Fia vocal tutorial) and Versilian Studios VCSL Saxello. These audio files are not bundled. Pinned sources, licenses and selected-file hashes are recorded in docs/audio-model-performance.md and the local source manifests.
