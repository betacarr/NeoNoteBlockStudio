# 大工程的钢琴卷帘编辑

0.1.33 改善了大量源音符下的钢琴卷帘查询。滚动、悬停、点选、框选、擦除和拖动预览按当前时间与音高范围取候选，不再为每个指针位置或重绘反复遍历整段源音符。力度栏按起音位置查询，屏幕左侧长音的尾部仍会显示，但不会在栏内凭空增加起音标记。

操作方式保持原有规则：FL 预设中放下音符后拖动会移动位置与音高，右边缘调整显示时值；Shift 框选，右键擦除，Esc 取消当前手势。拖动预览不会改写源数据，释放后才提交一次编辑，撤销与重做仍处理完整操作。

长音、零时值音符的六像素显示宽度、重叠音符的绘制顺序和最上层点选均保留。缩小到每像素多行音高时，命中查询会覆盖音符实际的一像素点击高度。选区从屏幕外移入、裁剪手柄、滚动后框选和擦除继续使用原来的精确几何判定。

当前源音符数组改变后重建索引；拖动开始时缓存移动选区的索引与边界，帧内只转换候选音符。组件只保留当前源索引，不为每个撤销状态保留一份。真正修改源音符、首次打开工程、全部适配和首次建立大选区仍需要处理相应的完整数据；全部音符都可见时仍绘制全部可见音符。

验证分为独立几何对照、实际组件回调、开发浏览器实际操作和 Windows 实包文件检查。十万音符的确定性工作量测试统计候选与字段读取次数，不把模拟画布的结果当作界面帧率或硬件延迟。详情见 [0.1.33 验收记录](verification.md)。
