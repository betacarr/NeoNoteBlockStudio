# 编曲片段多选与整组编辑

Windows 0.1.43 支持多个片段一起移动、独立复制和删除。钢琴卷帘仍编辑主片段的源音符；片段选区只属于编辑视图，不写入 NBSX。

## 选择片段

- 从编曲轨道空白处左键拖框，替换片段选区。Ctrl / Cmd＋左键可从片段主体或裁剪边缘开始拖框；加 Shift 保留原选择并追加。
- Shift 点击片段增减选择，不启动拖动。单击空白清空选择；单击片段在松手时收敛为单选。
- 拖动已选片段主体保留整个选区。仅按下时不会立刻丢掉其它成员；拖出去再回到原位不会增加历史。
- Ctrl / Cmd＋A 按当前编辑区工作：编曲区选择所有可见轨道中的片段，钢琴卷帘选择当前源音符。乐器筛选不会改工程或播放内容。

编曲区标题显示所选数量。筛选隐藏的成员仍保留在选区，并显示隐藏数量；点击「显示全部所选」后可继续整体编辑。主片段决定钢琴卷帘、轨道与混音通道的高亮。

## 移动、复制与删除

拖动任意已选成员，所有成员使用相同的时间差和可见轨道行差，保留彼此间距。时间边界限制整个组的偏移，不挤压成员间隔。跨轨时遵循[单片段目标规则](arrangement-gestures.md)，上下、左右边缘可自动滚动。

任何成员被隐藏、源轨锁定，或移动后会超出轨道范围、进入锁轨，整次编辑都会拒绝并说明原因。不会只移动其中一部分，也不会在跨轨失败时只移动时间。Esc、失焦、工程或选择变化取消未提交的拖动。有效释放只产生一步历史；撤销和重做恢复全部片段及当时的主片段、选区。

「独立复制」或当前预设的复制副本快捷键（FL 默认为 Ctrl+B）将整组选区复制到右边，偏移量等于从最早起点到最晚末尾的完整跨度。相对位置保留，每份副本的源、音符及 MIDI 消息都有独立身份；改一份不会同步到其它副本。循环仍是单独开关。

编曲区 Delete 删除全部所选片段；只清理因此失去引用的源，保留其它片段、其它独立源、便携资源和原始 MIDI。空选区 Delete 不改工程或重做历史。包含隐藏或锁定成员时整体拒绝，防止无意删除看不见的内容。

多选时，检查器的片段名称、长度、所属轨道与片段循环暂不批量编辑；先单击一个片段即可使用。拖动某片段裁剪边缘会先选中该片段，只调整它的播放范围。0.1.44 起 Ctrl+C / X / V 按当前编辑区复制、剪切、粘贴音符或片段；编曲区可跨工程粘贴并按需补轨，见[片段剪贴板](region-clipboard.md)。整组「独立复制」继续直接放在原选区右侧。

## 数据与试听

移动保留音符 tick、时值、音分、声像、源偏移与循环范围。跨轨后隐式音色、混音和 Delay 随目标轨道；显式音色覆盖保留。旧 MIDI NoteOff 输出轨路由仅在跨轨时清理，必要时分离共享源，保护其它引用及原始 MIDI。

播放中编辑无需重启输送。已经起音的采样自然结束，后续事件根据最新编曲安排。NBSX、MIDI 和 NBS 继续使用完整工程；视图筛选与选择不会缩小保存或导出的范围。

1469 项测试通过。实际界面完成空白框选、Shift 增选、整组横移和跨轨、拒绝锁轨／隐藏成员、独立复制后单独改名、删除及撤销重做、保存重开；18 份保存文件以独立原始 ZIP / JSON 完整比较，所有嵌入资源字节一致。另有含便携采样的连续播放跨轨及完整保存比较。持续按住 Ctrl / Cmd 拖框、拖动中取消和重入由实际组件回调覆盖，没有计作物理组合拖动验收。最终实包与详细边界见[验收记录](verification.md)。
