# 跨工程复制音符

Ctrl / Cmd+C / X / V 按当前编辑区选择对象：本页说明钢琴卷帘的音符，编曲区见[片段剪贴板](region-clipboard.md)。最新成功复制会替换上一种剪贴板内容，避免在错误编辑区粘贴另一类对象。

音符剪贴板记录来源工程的时间分辨率（PPQ）。粘贴到另一工程时，音符间隔和显示时值按拍数换算，跟随目标工程速度，不会因为两个 MIDI 文件采用不同 PPQ 而变快或缩短。

例如源工程为 480 PPQ，两个音符相隔 480 tick；粘贴到 960 PPQ 工程后相隔 960 tick，仍为一拍。组内最早起音对齐粘贴位置，其他音符保持相对间距；小数微时值、零时值、力度、声像、高度和微调音高保留。

## 音色与采样

跟随轨道音色的音符，粘贴后继续使用目标轨道的默认音色。显式覆盖音色的音符会携带对应音色定义和采样资源；资源已经存在且定义完全相同时复用，否则新建并重新映射引用。源工程和目标工程恰好使用相同 ID 时，不会覆盖目标已有音色或声音文件。

没有嵌入采样数据的外部资源仍保留原定义，并提示在目标工程中定位声音文件。复制音符只携带实际引用的音色和采样，不把原工程的 MIDI 归档、控制器轨道、参考音频或轨道 Delay 参数一并带入。

## MIDI 与撤销

释放力度和音符事件顺序继续保留。跨文档或跨轨道粘贴时，移除原 MIDI NoteOff 的来源轨道路由，让结束事件跟随目标音符所在轨道；相同文档、相同轨道的独立复制保留原路由。

粘贴音符和新增资源作为一次修改提交，撤销同时移除两者，重做同时恢复。成功后选中新音符并进入钢琴编辑区；空剪贴板、锁定轨道、缺失目标和无法迁移的坏引用不会产生半份修改。只读复制仍允许在锁定轨道上使用，剪切与粘贴受锁定保护。

## 验证范围

修复前，实际 0.1.28 桌面程序通过原生菜单执行 Copy → Open → Paste → Save As，回读确认 480 → 960 PPQ 的间隔和时值没有换算。新的核心、实际 App 命令及最终桌面文件回读分别检查拍数、自定义资源冲突、释放事件路由和撤销/重做。桌面检查走原生菜单与现有文件接口，文件选择返回值为测试夹具，没有冒充物理鼠标、系统剪贴板或外部 DAW 交换格式验收。
