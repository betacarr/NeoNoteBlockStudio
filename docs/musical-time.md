# 速度、拍号与循环

0.1.5 的编曲区、钢琴卷帘和顶部播放位置共用工程拍号。示例：PPQ 480，起始 3/4，第 2880 tick 变为 7/8，第 6240 tick 变为 4/4：

| 小节 | 开始 tick | 拍号 | 每一拍 tick |
| --- | ---: | --- | ---: |
| 1 | 0 | 3/4 | 480 |
| 2 | 1440 | 3/4 | 480 |
| 3 | 2880 | 7/8 | 240 |
| 4 | 4560 | 7/8 | 240 |
| 5 | 6240 | 4/4 | 480 |

播放位置采用“小节.拍.拍内百分位”，例如 7/8 中第二拍的一半显示为 `3.2.50`。BPM 始终表示每分钟四分音符数，顶部显示播放头当前生效的速度。

点击顶部拍号，或从播放菜单打开“速度与拍号”。可以在播放头插入节点、修改节点值、定位或删除节点；起始节点保留。编辑会进入撤销历史。面板打开时暂停试听。拍号在小节中途变化时，前一小节缩短，新拍号从该点开始新小节。相同拍号的重复 MIDI 消息保留，但不切开小节。已有音符的绝对时间不因拍号改变而移动。

吸附与新音符显示时值的 `1/4`、`1/16` 等均表示音符时值。例如 7/8 中的 `1/4` 仍长两拍。吸附以当前小节起点为基准，并包含小节终点；换拍前后不强制套用起始拍号。拖动一组音符或粘贴旋律时，保留组内相对时间。音符显示时值不截断游戏采样。

普通片段复制创建独立内容，包含独立的音符和 MIDI 消息。循环由片段的“片段循环”开关控制，循环周期是片段源内容长度。编辑周期内已有音符不会自动重设周期；添加到周期以外才延长源内容。钢琴卷帘按该片段第一次出现的工程时间显示标尺，循环光标按源偏移回绕。移动片段或修改工程拍号不会自动拉伸旋律或重写已存的循环周期。

MIDI 导入会把片段范围补足到实际小节终点。工程播放范围采用最后一个片段的终点；没有片段时采用第一小节。非循环试听和音频导出仍保留最后采样的尾音。NBS 导出使用真实秒数换算起音，不能表达的拍号信息会在转换报告中提示。

当前原生试听先离线渲染工程快照，修改后需重新播放才能听到新内容。速度编辑面板会暂停试听，顶部 BPM 在播放中只读。录入与原生播放期间实时更新、参考音频对齐和大工程交互仍待进一步验证。

0.1.18 起，原生音符起点按完整速度时间线换算为整数采样帧；循环先合成整圈与音符的时间，再统一舍入，避免半帧浮点误差。首次循环从真实冷前缀开始，后续保留跨圈尾音。原版类连续起音与浏览器离线循环分开检查，后者在 137 BPM、300 圈的观测中仍有最多一帧插值残差；这不表示完整游戏音乐时序已经验证。见[原生起音与循环记录](native-playback-timing.md)。

验证入口：`npm test`、`scripts/smoke-timing-desktop.mjs`、`scripts/verify-midi-interop.mjs`。桌面检查包含上述三种拍号的导航、标尺、当前 BPM、面板及保存，不等同于所有鼠标编辑路径都已自动覆盖。
