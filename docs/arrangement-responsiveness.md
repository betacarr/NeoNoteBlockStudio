# 大工程的编曲缩略图

0.1.34 将编曲区缩略图改为查询当前可见音符。滚动、缩放、移动或裁剪片段，以及面板宽度改变后的重绘，会复用当前源的查询索引。相同源的多个副本共用这份查询工作；音符与独立副本的编辑规则保持原样。

非循环片段按源时间查询，循环片段按源周期内的位置查询，并保留跨接缝的长音尾部与至少两像素的短音。尚未到达首次起音的远处源音符可以提前排除。画布仍只分配片段在当前视口内的宽度，横向或纵向不可见的源不会提前建立索引。

改音符、改变源周期、撤销和切换工程后，缓存会按当前源更新；删掉源时清除相应条目，不为每份撤销状态保留索引。轨道、片段、源与音色的查找也复用当前数组的映射，片段的原有绘制顺序不变。

修复了一处浮点边界：很大的源起音与偏移相减时，数学上接近片段末端的循环事件仍可能符合实际播放的半开区间。缩略图现在按实际起音表达式判断有效周期与可见像素，保留这些末端事件。密集重复笔画仍合并为覆盖相同位置的区间，并保留实际存在的微小间隙。

首次索引、源变化后的重建和真正的工程编辑仍可能处理完整源。密集重叠或全部适配时，很多音符确实都可见，查询也会相应返回较多候选。目前仍保留全部轨道与片段 DOM，尚未加入完整虚拟化。

同一十万稀疏音符、两个可见副本的实际组件对照中，后续滚动、缩放、尺寸重绘的源字段读取量从 1200000 / 1200000 / 600000 降为 14 / 14 / 7，绘制矩形逐项一致。首次构建成本单独记录，以上数字不代表真实界面帧率。实际开发浏览器另检查大 MIDI 首尾、移动、撤销、尺寸变化和两次循环接缝；最终实包的菜单/文件检查独立记录。见 [0.1.34 验收](verification.md)。
