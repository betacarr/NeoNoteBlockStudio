# 平台支持

## Windows x64

提供安装版与便携版。安装版可选择安装目录，并注册 NeoNBS 的 NBSX 工程关联；卸载默认保留用户资料。普通启动与编辑不需要 Node.js 或 JDK。默认试听使用内置采样，不要求安装游戏或 Java；原生版本校对需匹配的本机 Minecraft 资源，部分版本另需 Java 运行环境。

## macOS

源码保留 macOS 构建入口，尚未提供经实际安装、输入、文件生命周期和声音验证的安装包。构建命令不等于平台验收完成。
