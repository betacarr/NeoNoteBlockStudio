# 混音器与乐器筛选

从底部状态栏或「视图 → 混音器」打开。混音器保留原轨道编号、颜色和音符盒垫块图标，右侧固定显示总输出。

## 按乐器查看轨道

编曲区与混音器共用同一个筛选。选择某个乐器后，两处只显示默认使用该乐器的轨道；数字表示匹配数与总轨道数。自定义乐器同样支持，名称相同的不同乐器仍按各自 ID 区分。

筛选依据是轨道的「默认音色」，单个音符的音色覆盖不参与。筛选只改变显示，不会静音、删除音符、改变播放或导出范围，也不会生成撤销记录或改变工程保存状态。打开另一个工程后恢复显示全部轨道。

被隐藏的当前选择仍然保留。可点「显示当前轨道」或「显示所选音色」切换到它的乐器，也可点「清除」恢复全部。若改换音色后所选筛选已没有匹配轨道，会保留 0 条提示和清除入口；总输出始终显示。

## 选择与定位

点击编曲区轨道、片段或混音器通道，会同步当前轨道与检查器；对应混音通道用边框和背景高亮。混音器可反向选择编曲轨道。目标在屏外时，编曲区只调整自身纵向滚动，混音器只调整自身横向滚动，时间轴横向位置不变。

正常桌面高度下，音量、声像与 M/S 按钮直接显示。小窗口首次打开混音器时，中央工作区会滚动以揭示它。之后的电平刷新、筛选与选轨不会反复抢回中央滚动位置。轨道区有横向滚动条；高度不足时可在通道区域纵向滚动到数值和 M/S 按钮，总输出有自己的纵向滚动。

## 混音操作

| 控件 | 范围与操作 |
| --- | --- |
| 轨道音量 | 0～400%，显示对应 dB；100% 为 0 dB，不截去已有的大于 100% 增益 |
| 轨道声像 | −100～100%，负数向左、正数向右，0 居中 |
| 总输出音量 | 0～200%，与顶部总音量同步 |
| 精确输入 | Enter 确认、Esc 取消，离开输入框提交；非法值拒绝提交 |
| 复位 | 点「0 dB」恢复音量 100%，点「居中」恢复声像；也可双击参数标题 |
| M / S | 分别控制轨道静音、独奏；选中高亮不受静音状态影响 |

音量、声像拖动期间即时试听临时值，松手只提交一次，可一步撤销。取消、失焦、锁定或更换工程会还原到最新已提交值；试听预览不会额外写历史或工程。锁定轨道不允许调整音量与声像；M/S 保持可用，与编曲区一致。参数修改保存到 NBSX，源音符、时值、MIDI 事件和资源保持完整。

**0.1.40 起，编辑默认使用实时试听。** 音量、声像、静音、独奏与总输出即时作用于正在发声的声音；音符、乐器、Delay、片段和速度的修改更新后续发声，无需暂停再播放。撤销与重做也会更新实时试听。数字输入仍在确认或离开输入框后提交。

调度器撤回尚未起音的旧事件，保留已经起音的采样自然尾音；它不会因为编辑音符的显示时值而截断采样，也不会重发已经过去的音符。循环中的前圈回声与速度修改的当前音乐位置分别保留。修改已起音音符自身的音高、力度或音色，只影响后续事件；轨道混音控件会调整其当前尾音。

「设置 → 声音与资源 → 试听方式（本机）」可明确选择「原生离线对照」，用于声音校对。它仍是整曲离线快照，只有总输出电平，修改后需重新播放。切换方式会停止当前播放，每次启动默认实时试听；旧 NBSX 中的 `previewEngine` 字段原样保留。原生 WAV 导出独立于编辑试听方式，继续按最新工程参数处理。实时试听仍与原版处理存在近似差异，不能代替声音一致性验收。

0.1.41 起，实时试听和 Web WAV 保留实际音高，超音域也可正常发声；原版音域提示继续显示。原生离线对照与原生 WAV 保留目标游戏的音高限制。见[编辑试听音高](editor-pitch.md)。

本次未增加总线、发送或均衡器。Space / Shift+Space 在混音器所有控件上统一播放／暂停，不触发 M/S 或输入空格；Enter 保持正常控件操作。更换工程、重新加载声音资源等全局操作仍会停止播放。

## 电平显示

实时试听显示真实的分轨与混合总输出峰值，总输出包括参考音频，不使用推子数值或最大分轨值代替。视觉采用 −60～0 dBFS 刻度，较轻的声音也能看到电平；悬停显示实际峰值和 dBFS。小窗口下电平条完整可见。电平随混音修改更新，初始静音／音量为零的声音也可在其自然尾音期间恢复；停止时归零。原生离线对照仅提供真实总输出，分轨显示不可用标记。

0.1.39 的[筛选与混音器验收](verification.md)仍保留。0.1.40 新增实时信号图、未来事件替换、尾音、循环、速度、参考音频和拖动取消检查；实际界面在连续播放中修改混音、音色、Delay、速度并撤销，五份完整 ZIP 回读保留 34 个源音符与全部采样。Windows 实包另验证旧工程默认实时播放、两轨与总输出电平、保存和重启。见[实时试听验收](verification.md)。这些不是 Minecraft 声音一致性或音频设备验收。
