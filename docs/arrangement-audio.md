# 音频片段与分轨组（本地开发版）

本轮按 [Logic Pro Mac 的 Stem Splitter 操作](https://support.apple.com/en-mz/guide/logicpro/lgcp61bae908/mac)、[拖放创建轨道](https://support.apple.com/guide/logicpro/create-tracks-using-drag-and-drop-lgcpd1e675e5/mac) 的工作流接通现有 NeoNBS 编曲区。沿用其片段级处理、原轨下方建立分轨组、只静音原片段的语义，没有复制 Apple 的模型或硬件要求。

## 实际入口

- 「文件 → 导入音频文件」会把完整音频放到调用时的播放头位置。选中普通音频轨时导入该轨，选中音符轨时新建音频轨。普通音频轨的右键菜单也可直接导入到该轨。文件对话框通过本地文件路径流式读取，源文件时长上限为两小时。
- 将 WAV、AIFF、FLAC、OGG Vorbis、MP3、M4A 或 AAC 拖到编曲时间线。拖到空白处或音符轨会新建音频轨；拖到未锁定的普通音频轨会增加片段。时间线上的位置随鼠标、水平滚动和网格吸附计算；拖到轨道标题时使用播放头位置。
- 每批最多拖入 16 个文件。桌面版拖入本地文件和文件对话框使用同一读取方式；只有无法获得本地文件路径时，才限制单文件 64 MiB、合计 256 MiB。多文件可以各自新建轨道并对齐，或在目标音频轨顺序排列。M4A 和 AAC 需要系统上有可用的 FFmpeg。
- 主播放／暂停、定位及工程循环使用同一 AudioContext 时间轴；音频按原始秒数播放，不随 BPM 自动拉伸。轨道 M/S、音量和声像作用于播放，分轨组的 M/S、音量、声像控制全部子轨。组可以折叠。
- 选中音频片段，在编曲区使用 **功能 → 大分轨拆分器**，或右键片段选择 **处理 → 大分轨拆分器**。选择预置、声部或子混音后点「应用」，完成后直接在编曲区试听。默认提取全部六类大分轨。
- 分轨一次只接受一个音频片段。成功后在原轨下创建分轨组和同位置子轨，并选中新生成的片段。原片段被静音并保留。创建组和片段静音是一次可撤销操作。可将取消选择的声部合成一条子混音。
- 右键普通音频轨标题若只有一个片段，可直接进入该片段菜单；多个片段时要求右键具体片段，避免猜测目标。
- 右键音频片段 → **和弦 → 分析和弦**。结果保存在片段上，可校正、应用到全局和弦轨，或将全局和弦应用回片段。详见[分轨和和弦操作](audio-task-dialogs.md)。

CPU 始终默认。GPU 仍是可选实验路径，其自然音乐 CPU/GPU 数值一致性未全部通过，状态沿用 [模型实测记录](audio-model-performance.md)。声部分离仍为五类预测加其他残余，不是原生六类互斥模型。模型缺失时使用既有资源提示及确认下载，不自动下载安装 GPU 包，也不重新获取已经校验的权重。

## 资源与编辑

音频使用 NBSX 旁的 `工程文件名.nbsx.assets/audio/<sha256>.wav`。另存、打开、搬移沿用托管资源校验；请一起移动 NBSX 和 `.assets`。缺失时右键片段“重新定位音频素材…”，只接受与原描述的完整 SHA256、采样长度及通道一致的文件。

拖动片段主体可修改起点或移到另一条未锁定音频轨。拖动下缘两端可裁剪或恢复源文件的播放范围。选中音频片段后，将播放头移到片段内部，使用「编辑 → 在播放头拆分片段」或片段右键菜单拆成两段。裁剪和拆分都引用原 WAV，支持撤销，已有和弦标签会随可见范围显示。再运行大分轨拆分器时，输入为所选片段当前可见的音频。

音符片段不能移到音频轨，也不能在音频轨中创建音符。普通音符／鼓组和既有独立音频辅助工程仍可打开。普通音频片段重叠时同时混音。时间伸缩、交叉淡化、录音及批量分轨尚未实现。

桌面版可从「文件 → 导出所选音频片段为 WAV」或片段右键菜单导出。单选时命名并保存一个文件，多选时选择文件夹，每段各生成一个文件，同名文件会自动追加序号。导出使用源音频的可见范围，保留采样率、声道和电平。需要轨道混音时，使用现有的工程实时 WAV 导出。

实时 WAV 导出包含音频片段。NBS／MIDI 不能表示普通音频，界面给出音符导出提示；含音频片段的工程不允许用原生游戏对照／原生 WAV 静默漏掉音频，应使用实时试听／WAV。完整缓冲播放有 1.5 GiB 解码预算，未验收长曲和低配机器。

## 本轮证据

真实八秒 CC0 独立录音混合，UI → IPC → 已下载官方模型 → CPU 工作进程实际运行 **41.561 秒**，非替身结果。导入、已有音轨追加、真实主输出电平、六子轨编组、区域级静音、单次撤销／重做、精确位置、工程重开和波形均通过：`.local/arrangement-audio-ui/run-hn8L41/report.json`，截图同目录 `audio-stem-stack.png`。

独立恢复 QA：`.local/arrangement-audio-recovery/run-5Rva23/report.json`。项目和资源搬移、错误格式、真实解码失败后重试、多文件明确选择、真实模型前向期间取消（0.033 秒）、缺失素材报错及完整校验重定位均通过。取消／失败不修改工程，也不静音源片段。

上述是功能／数值检查，没有声称完成主观听感验收。文件属于明确许可的本地测试素材，不使用或上传用户私有音频。没有改动用户原工程、窗口、系统驱动或网络设置，没有推送／发布。

最终编组混音／移动定位 QA：`.local/arrangement-audio-controls/run-87GbK4/report.json`。组独奏后通过实际总输出电平验证组静音／恢复出声，片段移动一拍并撤销恢复，放大及水平滚动后拖入位置与独立计算值一致。冷启动播放必须等待所有片段解码，已补独立回归覆盖。

WAV 24-bit、FLAC 24-bit、OGG Vorbis 和 MP3 的实际 worker 解码均通过，0.5 秒原录音节选完整保留 22050 个 44.1 kHz 立体声采样帧；这是格式检查，不是分离质量证据。报告 `.local/arrangement-format-qa/report.json`。

最终构建已更新现有“NeoNBS 最新开发版”快捷方式引用的 dist 与 dist-electron。全套 2199 项通过、1 跳过（排除既有 publication-audit 环境检查），最后元数据／冷启动／时间轴增量 13 项通过。最终缓存复验 `.local/arrangement-audio-ui/run-zYhihA/report.json` 还验证重新打开原片段能复用分轨时保存的和弦／速度分析；它复用真实 CPU 结果，实际前向证据仍为前述 run-hn8L41。

`start-audio-trial.cmd` 现打开最终编曲区音频工程并使用已下载模型的 QA 配置；既有独立辅助工程保留。总交付记录 `.local/arrangement-audio-delivery-report.json`。开发快捷方式使用其独立配置；若该配置尚无模型，仍会按产品既有流程提示下载，不会自动从 QA 配置复制或重新下载。
