# 音符力度编辑

0.1.49 修复多选力度拖动抹平原有强弱的问题。先选中音符，再在下方力度区拖动其中一根力度条：所有有效选音增加或减少同一个数值。例如 25%／75% 上移 12.5 个百分点后变为 37.5%／87.5%。这不是按比例缩放，也不是力度自动化曲线。

一组中任一音符达到 0% 或 100% 时，整个增量一起停止，保留强弱差。例如 25%／75% 继续向上只能到 50%／100%，向下只能到 0%／50%。按下时不跳值，多选时没有拖动的点击只保留选择，不产生修改或清空重做。

单个音符继续按力度区的点击位置设置绝对力度。要把多个音符统一成同一个值，在检查器使用「力度」控件；两个入口的用途不同。界面的整数百分比显示不会将工程中的小数力度改成整数。

拖动预览不写源数据，松手一次提交、一步撤销。Esc、失焦、目标变化和锁定沿用原有取消规则。起音、显示时值、音高、声像、音色覆盖、MIDI 释放力度和消息顺序均保留，原始 MIDI 文件与采样字节不改写。

另修复完整音域缩放时的框选命中：音高行小于 1 像素时，框选使用与点选、擦除相同的音符矩形高度，避免漏掉仍可命中的音符。实际界面在 180 像素高画布中核对了 Ctrl 点击框选三音，再修改微调并保存，确认修改对象身份；连续框选移动另有组件回调测试。

实现只在手势开始时计算选音力度范围，每帧仍按可见候选绘制，不扫描整个选区。十万音符的候选工作量测试是性能回归证据，不等于所有机器的帧率保证。
