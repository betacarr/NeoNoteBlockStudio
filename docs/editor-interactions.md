## 钢琴卷帘缩放（0.1.52）

标题栏分别提供「横向」与「纵向」滑杆、减号和加号。横向调整时间比例，纵向调整每个半音的行距；点击轴名恢复该方向的默认大小（纵向为 18 像素）。两轴独立，标题栏纵向缩放保持视图中央音高。

Ctrl / Cmd＋滚轮保持原有横向缩放；Ctrl / Cmd＋Shift＋滚轮按鼠标所指音高纵向缩放。普通滚轮上下滚动，Shift＋滚轮左右滚动。纵向手动行距为 0.25～48 像素，「全部／所选」仍按音符范围自动适配，并将实际行距同步到滑杆；切换片段仍沿用现有自动定位规则。缩放不修改工程、音符或撤销记录。

1981 项测试（97 文件）通过；真实界面检查加减、滑杆、复位、两轴独立及放大后音符移动／一步撤销，五份完整保存件保持所有字段、ID 和资源（仅根 modifiedAt 除外）。修饰键滚轮与拖动中取消另由实际组件回调覆盖，没有声称物理组合输入验收。[本版记录](verification.md)。

## 钢琴卷帘框选

按住 Ctrl（也支持 Cmd）再用左键拖动，可从音符主体、音符右边缘或网格空白开始框选，替换原选择；不会绘制、移动音符或调整时值。Shift＋左键保留追加框选，Ctrl / Cmd＋Shift 同样将框内音符加入原选择。三个操作预设使用相同规则；Ctrl 点选不再用于增减单个音符。

框选仅作用于音符网格。键盘仍试听，标尺仍定位，范围手柄仍裁剪，力度区仍左键调整力度；中键平移、右键擦除和 Ctrl / Cmd 滚轮缩放保持原用途。Esc、取消指针或失焦会放弃框选并恢复之前的选择，不修改工程。

0.1.41 新增 21 项真实组件回调测试，覆盖三种预设的 Ctrl 持续拖框、追加、取消与区域优先级。实际界面另核对 Ctrl 在音符主体／右缘／空白处点击、Ctrl+Shift 追加、两音一起移动和一步撤销；四份完整工程 ZIP 回读保留源音符与资源。当前操作工具的拖动接口不支持保持修饰键，持续 Ctrl 拖框仍属于组件覆盖，未计作物理组合拖动验收。[本版记录](verification.md)。

编曲缩略图在滚动、缩放、片段预览和尺寸变化时复用当前源索引。循环接缝、长音、短音宽度和片段绘制顺序保留，修复大坐标小数边界的漏画；详见 [编曲区响应](arrangement-responsiveness.md)。

## 0.1.33：大量音符的局部查询

钢琴卷帘的画面、点选、框选、擦除与拖动预览按可见候选处理，保留长音尾部、短音宽度、重叠顺序与取消/撤销规则。十万音符的实际操作与工作量对照分别记录，详见 [大工程钢琴编辑](piano-responsiveness.md)。

## 0.1.29：跨工程音符粘贴

不同 PPQ 的工程之间粘贴音符会保持拍数与时值，并迁移显式自定义音色及采样；同 ID 的不同资源不会覆盖目标内容。粘贴音符和新资源一起撤销/重做，成功后选中插入的音符并进入钢琴编辑区。跨文档或跨轨的 MIDI 结束事件使用目标轨道，保留释放力度。详见 [音符剪贴板](note-clipboard.md)。

## 0.1.28：导出参数与结果

NBS 导出时间网格按起始 BPM 自动计算，提供 BPM ÷ 7.5 和 BPM ÷ 5 两种预设。点击一次「导出文件…」即完成生成、检查与保存，问题自动提示。参数或工程改变后，下次点击使用新内容；后台迟到结果不会保存。重复导出被拦截，取消或失败可直接重试，旧回调不会关闭新面板。详见 [导出工作流](export-workflow.md)。

## 0.1.27：数值输入与轨道效果

音符属性、片段长度和 Delay 参数采用先输入、后提交的方式。可以完整输入负号、小数和细微时间；Enter 或离开输入框只提交一次，Esc 取消。越界内容按 Enter 会标记无效并保留输入，离开时恢复旧值；未确认的有效输入会在保存或导出前提交，无效输入会阻止命令。未确认输入也显示未保存状态。只聚焦再离开不会舍入源数值或增加历史，切换目标、撤销或锁定后旧输入不会改到新目标。

选中轨道后，检查器提供「Delay 回声」。时值关联模式支持 ADSR 和提前释放，自由尾音独立于音符时值；效果只派生试听和导出事件，保留钢琴卷帘中的源音符。详见 [Delay 参数与导出](delay-effects.md)。

0.1.7 提供以下操作：

- 拖动编曲区与钢琴卷帘之间的分隔条调整高度；双击恢复默认，方向键微调，Shift 加快调整，Home/End 到允许范围两端。比例保存在本机。小窗口同时打开混音器时，工作区可以纵向滚动，保留编辑面板的最小尺寸。

- 两个时间标尺均支持按住拖动定位，靠近边缘时继续滚动。
- FL 预设下，左键放下新音符后继续拖动会移动时间和音高，保持所选显示时值。拖动已有音符主体也移动；仅右边缘调整时值。很短的音符仍保留可移动的主体区域。
- 音色库和轨道头显示对应音符盒垫块，映射及素材说明见 [图标记录](instrument-block-icons.md)。

## 副本播放范围

参照 [Logic Pro 的片段边界裁剪](https://support.apple.com/en-qa/guide/logicpro/lgcpf7c0c964/mac)，编曲区片段与钢琴卷帘标尺下的范围带都有左右手柄。拖动改变该副本的起点或终点，保留源音符与 MIDI 消息。裁掉的起音变暗，拉回边界可以恢复；不会截断已经起音的原版采样。

绿色框表示当前副本使用的源范围；橙色虚线表示源片段结束。标尺下的范围带表示副本完整播放长度，并显示工程中的开始、结束位置。循环由独立开关控制，源周期与副本播放长度分别保存。循环副本当前只绘制一个源周期供编辑，未在网格中重复绘制所有循环。

左边界向源零点以前扩展时，为源内容前置空白，并同步平移源音符和 MIDI 消息，保持原有音符在工程中的绝对起音。共享源会先独立复制。右边界裁剪保留内容；在源内编辑、录入或继续增长源内容时，不会自动取消已裁好的边界。只有原本跟随源末尾的非循环副本才自动增长。

## 验证范围

专用浏览器测试工程中实际操作检查了：面板拖动与键盘调整；双轴滑块；两处标尺拖动；FL 放置拖动保持 1/16 显示时值、右边缘单独延长；范围左右边界缩短后原音符数不变，拉回后播放起音数量恢复；Liquid Glass 开关与重开保存，以及启用后继续编辑。核心回归覆盖左右裁剪、偏移、循环回绕、共享源隔离、MIDI 消息平移与自动增长条件。桌面验收入口见 README。

明确选择“原生离线对照”时，播放的是预渲染快照，编辑后需要重新播放以听到更新。0.1.40 起默认“实时试听”，混音即时生效，音符等编辑更新后续发声；详见[实时混音与验证范围](mixer.md)。大工程、所有快捷键组合与所有屏幕尺寸仍需更广泛交互检查，历史界面操作也不等于当前实包物理输入复验。

## 焦点与剪切修复

后续实际检查确认：在轨道名称输入框全选后点击钢琴音符，旧界面仍把键盘焦点留在名称框。现在钢琴画布主动取得焦点；编曲片段、空白区域与标尺也接管焦点，按钮、输入框和选择框继续使用原生焦点。当前浏览器通过 CUA 实际点击与 Delete 检查：音符由 16 减至 15，名称仍为“玻璃旋律”，撤销恢复 16；点击片段后焦点属于编曲区。

这次历史焦点修复为音符复制和剪切加入与菜单一致的有效选择检查。空选择、已失效选择或编曲焦点下不会清空音符剪贴板，也不会误删整个片段。锁定轨道允许只读复制，禁止剪切；合法音符剪切仅移除所选音符，保留片段和源。当时片段只通过“独立复制”处理；0.1.44 已新增按编辑区分发的[片段剪贴板](region-clipboard.md)，编曲区复制／剪切现在处理有效片段选择。

真实菜单剪切一音、粘贴及两次撤销通过，四个片段始终保留。Ctrl+X / Ctrl+V 的浏览器工具包装受到虚拟剪贴板限制，这次没有把它算作键盘剪贴板验收；命令守卫另有直接执行实际 App 函数的单元检查。当前源码、原始状态与三张截图见[焦点及剪贴板记录](verification.md)。这不是实包原生鼠标验收或所有快捷键组合的全面验证。

## 锁定粘贴与裁剪预览

锁定轨道在粘贴或独立复制已选音符的命令入口拒绝编辑，保留原有有效选择和剪贴板；菜单使用同一守卫，只读复制仍可用。编曲边界拖动改用当前片段的局部预览，按最终裁剪范围更新缩略图；向源零点以前扩展时预览前置空白。移动期间不提交工程，松手只提交一次；取消或失去指针捕获恢复原位置、宽度和缩略图。

开发浏览器实际 CUA 检查：锁定时 Ctrl+B 保持 2 个播放起音、选中 1 音；解锁后 Ctrl+B 成功增加到 3 个。锁定菜单允许复制，禁止剪切、粘贴和独立复制；解锁菜单粘贴及单步撤销通过。左裁后播放起音 2→1，左扩保持 2；两者均能一步撤销恢复原几何。Ctrl+C / Ctrl+V 仍被浏览器工具拦截，未计入实际键盘验收。拖动中缩略图、取消和丢失捕获未由 CUA 观察，仅由实际组件函数的惰性数据探针与播放起音几何对照覆盖；四个编辑器套件共 50 项通过，类型检查通过。[本轮源码、原始记录与截图](verification.md) 分别记录这些范围，不代表新版实包鼠标或帧率验收。

## 小窗口滚轮隔离

0.1.15 修复同时开启混音器时的滚轮串动。钢琴与轨道名称区域改用可取消默认滚动的监听器；手势到达内部边界时也不会滚动外层工作区。编曲网格的原生滚动区同时限制边界传滚。

实际 CUA 输入复现旧行为：钢琴滚动 49 像素时，工作区也滚动约 49 像素；轨道列表滚动约 27 像素时，工作区同样移动。修复后，在同一紧凑窗口中，钢琴上下、横向、上下边界与轨道列表滚动均保持工作区位置不变。Ctrl/Shift 路由和挂载清理另以实际源码监听器纯探针核对，没有合成浏览器输入。[滚轮记录与截图](verification.md) 明确区分开发浏览器输入与实包检查。

0.1.17 实包另通过实际主进程原菜单 → preload IPC → App 命令检查。锁定轨道的粘贴、复制所选和剪切均保留两音符及有效选择；只读 Copy 可继续使用。相同未锁 fixture 的粘贴/独立复制成功增加两音符，撤销恢复，五份保存工程完整回读一致。它通过“全选音符”命令建立钢琴命令域，记录的 DOM 焦点仍可为 BODY；没有将此说成真实键盘或原生鼠标验收。[实包菜单记录](verification.md)。

## 0.1.22：空轨道、撤销与编辑范围

轨道选择与片段选择现在分别保存。点击没有片段的轨道，检查器保持该轨道，钢琴区显示“在当前轨道创建片段”；Delete 不会借用其他轨道的片段。点击有片段的轨道会保留该轨道当前片段，或选择该轨道的第一个片段。

撤销、重做同时恢复工程和当时的轨道、片段、音符选择，以及钢琴 / 编曲操作范围。音符复制后撤销，再按 Ctrl+B 仍复制原来选中的音符；钢琴区没有有效音符选择时 Ctrl+B 不产生修改。编曲区的“独立复制”按钮始终用于片段。

空选择下的删除、量化和移调保持原样；重复设置同一音符属性、量化已经对齐的音符、将最高音继续向上移调，也不会增加历史或清空重做。真正修改后的选择仍可随撤销、重做恢复。

实际开发浏览器 CUA 操作先复现了空轨道 Delete 误删其他轨道，再检查修复后的空轨道 Delete、片段复制后撤销、音符复制 → 撤销 → 再复制，以及空选择按键后仍可通过重做按钮恢复。此次浏览器 Ctrl+Y 未确认送达，未计为键盘重做验收。最终 Windows 实包另以实际原生菜单 / 现有 preload IPC 完成 11 次完整 NBSX 保存回读，检查非首轨音符复制与空选择重做保护；它不代表实包物理鼠标或键盘检查。两类范围分别记录在[本版证据](verification.md)。

## 0.1.23：擦除、框选与取消

擦除工具或网格右键按住后，会沿实际指针线段擦除触及的音符，包含两次位置事件之间经过的短音符，不会按整个外包矩形删除。路径限制在音符网格内，经过键盘、标尺或力度区不会擦除这些区域背后的音符。重叠处单击只擦顶层；拖过重叠处会擦除路径触及的各层。一次按下到松手只提交一次，整段可以一步撤销。

力度区仅左键调整，右键保持原样。Shift＋左键从音符或空白处都能开始框选，将框内音符加入原选择；中键仍用于平移，右键仍用于网格擦除。

Esc 取消尚未提交的音符绘制、移动、时值、力度、擦除或范围裁剪，恢复拖动前的选择。画布或窗口失去焦点、当前指针被取消时也会取消编辑；无关指针的取消事件不会中断当前手势。若编辑中切换片段、改变源音符或锁定轨道，旧手势直接失效，松手不会继续写入旧目标。定位与平移的已到位置会保留，取消只停止继续拖动。

开发浏览器通过实际 CUA 输入复现了力度区右键改成 30% 的问题；修复后右键保持原来的 83% 与重做记录，左键仍可改成 30%。另检查四音符划过擦除与一步撤销、重叠处单击 5→4 / 划过 5→3，以及 Shift 在重叠音符上开始选择后选中两音且保留重做。Esc、多指针、切换片段和中途锁定由实际组件回调的单元测试检查，未冒充物理鼠标或键盘验收。[本版证据](verification.md)。

## 0.1.24：自动定位与显示范围

打开 / 导入工程或切换当前片段后，钢琴视图会定位到该副本使用的源音符和音域，正常编辑时保持当前视口。若当前播放范围没有音符，仍可查看保留在源中的内容；空片段以中央 C 附近开始。新打开同一份工程也重新定位，不沿用打开前的滚动位置。

钢琴标题栏的“全部”显示当前片段的全部源音符，包括裁剪范围外保留的内容；“所选”只围绕当前有效选择适配。两者同时调整时间缩放、音域行高和滚动位置，不展开所有循环副本，也不修改音符、选择、播放范围或工程历史。未选音符时“所选”禁用。相同操作可从“视图”菜单进入。

宽音域和长乐曲可以缩小到整体概览；选中局部再按“所选”回到局部视图。缩放按钮与滑块围绕视口中心缩放，Ctrl / Cmd 滚轮围绕鼠标下的时间位置缩放。改变面板尺寸后，可以再次按“全部”适配新的可见范围。

实际开发浏览器检查了示例低音轨自动显示八音、“全部” / “所选”切换、保留单音选择与未修改状态，以及复制 → 撤销后仍能保留重做。实际组件回调另检查低音打开、同一视图内编辑不跳动、重新定位、适配及缩放锚点；独立几何测试含十万音符与完整 128 音域。实包检查和验证范围见[本版证据](verification.md)。

## 0.1.25：编辑焦点与菜单

点击编曲区或钢琴卷帘的标题、按钮、滑块等控件，会将快捷键归属切到对应面板；Tab 进入控件也一样。当前编辑区标题栏有细线提示。点击标题空白会解除检查器里的文本输入焦点，输入框和其他控件则保留自己的按键与默认操作。

例如，点击轨道后再点钢琴“全部”，Delete 只处理钢琴选择；未选音符时保持原样。选中音符、点击钢琴标题后 Delete 删除音符；点击编曲标题后 Delete 则删除当前片段。删除与复制仍遵循轨道锁定、独立副本及撤销规则。

界面顶部菜单控件持有焦点期间，编辑快捷键不会穿透工程。方向键在菜单中导航，Enter 激活按钮，Esc 收起菜单并回到对应标题按钮；Tab 可正常移出，离开菜单栏时收起菜单。关闭下拉后，仍聚焦的菜单标题也保持这一按键隔离。0.1.25 当时的空格激活规则已由 0.1.37 全局播放／暂停规则取代；顶部说明为当前行为。

实际 CUA 开发浏览器输入复现旧版“全部”后 Delete 将示例低音整段删除（96→80 显示音符）。修复后，未选音符的 Delete / Ctrl+B 保持 96 音符与四个片段；标题切换分别删除一个源音符（96→94）或整段（96→80），撤销恢复。Tab 从分隔条进入“全部”后 Ctrl+B 复制一个源音符（96→98），菜单方向键与 Enter 明确复制片段仍成功（96→112）；菜单 Delete / Backspace / e / Ctrl+B 不修改工程。滑块、滚动条和分隔条方向键另保留其原生操作。18 项实际组件回调测试覆盖其余事件分支；这些与实包菜单 / IPC / 文件回读分开记录，未声称原生窗口物理按键验收。见[本版证据](verification.md)。

## 0.1.26：所选音符整体移动

钢琴区左右方向键按当前网格移动选音，Shift＋左右键按四分拍移动；关闭吸附时左右键移动 1 tick。这里移动的是同一段距离，不将起音重新吸附到网格，因此导入 MIDI 中原有的细微时间偏差会保留。三个操作预设共用这组固定按键，设置里的快捷键清单与帮助会显示说明。

上下方向键移调，Shift＋上下请求八度移调。无论时间还是音高，所选组共享同一受约束的偏移；如果整组即将超出零点或 MIDI 0–127，只移动到最后合法位置，保留组内间距。例如 [120,126] 请求升高八度后为 [121,127]，不会分别压成 [127,127]；组中已经有 127 时继续升高则保持原样。音符显示时值、力度、声像、单音符音色和 MIDI 来源信息均保留。

这些键盘命令和量化只在钢琴编辑区处理有效选择。切到编曲标题时保留音符选择供稍后继续编辑，但不会继续移调、移动或量化这些音符；量化按钮同步禁用。锁轨和空选择不修改工程，边界没有实际变化时也不增加历史或清空重做。检查器的显式属性编辑继续可用。

实际 CUA 开发浏览器先复现编曲标题持有焦点时上方向键将 F♯3 改成 G3；修复后上方向键、量化、左右移动保持工程及重做。另确认 1/16 移动为 0.25 四分拍、Shift 移动为 1 四分拍、关闭吸附后读数为 0.001（界面按三位小数显示，精确 1 tick 由实际 App 命令测试核对）、八音整体移动和一步撤销，以及文本输入中的方向键保护。十二份只读 DOM 检查点和前后截图记录了实际输入；纯函数、实际 App 命令回调与 Windows 实包命令 / 文件回读分别记录在[本版证据](verification.md)，未声称原生窗口物理方向键或按住连发验收。
