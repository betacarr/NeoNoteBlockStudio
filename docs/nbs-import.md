# NBS 导入与相邻乐器层

导入 NBS 时，相邻且仅使用同一种乐器的层会组成一条乐器轨道和一个可编辑片段，钢琴卷帘可一次查看、编辑这些层的全部音符。同音同时间的音符仍分别保留。

遇到不同乐器、空层或单层多乐器时开始新的分组，不跨过中间层合并。自定义乐器按原始乐器编号区分，同名不代表同一种采样。Tempo Changer 仍转换为工程速度事件。

原层的音符时间、音高、微调及有效音量、声像保持。合并层的音量或声像不同时，这些差异写入对应音符，合并轨道使用音量 1、声像居中；相同混音参数保留为轨道设置。原始层名称、设置和各音符的层来源保存在工程来源信息中。

锁定／静音／独奏状态不同的层保持独立轨道，并显示导入说明，以免改变播放结果或编辑权限。NBSX 保存与重开保留分组及来源信息；导出 NBS 时仍按导出器的可容纳音符规则安排层，不承诺复原原文件的层布局。
