# 编曲片段与参考音频的拖动

在编曲区拖动片段主体会移动片段，拖动左右手柄会裁剪当前副本的播放范围。拖动过程中显示预览，松开后提交一次，可以一步撤销。裁剪不删除源音符，扩回范围可恢复播放。

0.1.43 增加框选、Shift 增减选择与整组移动／独立复制／删除。多选保持相对时间和可见轨道间距，任何成员隐藏或锁定时整次拒绝；检查器属性与裁剪仍按单片段处理。操作及边界见[片段多选](arrangement-groups.md)。以下保留 0.1.42 单片段交互的原始验收范围。

## 0.1.42：跨轨移动

按住片段主体拖到目标音符轨道，可同时调整时间和轨道；只上下移动时保留开始位置。指针靠近上下边缘会自动滚动，靠近左右边缘继续沿时间轴滚动。预览使用目标轨道颜色，显示目标名称并标出落点；拖动右／左裁剪手柄仍只调整范围。

目标轨道锁定时显示拒绝提示，释放后恢复原位置和原轨道。跨轨落点必须在编曲视口内，标尺、参考音频轨和筛选后的空白区域不会作为目标；不会偷偷移动到隐藏轨，或在拒绝跨轨时只提交水平移动。同轨横移保留原有左右边缘滚动和边界释放行为。无变化与取消不增加历史，也不清空重做。

也可在检查器使用「片段所属轨道」下拉，保持当前时间并移动到明确指定的未锁轨道，包括暂时被乐器筛选隐藏的轨道。筛选条件保持不变；可点「显示当前轨道」或清除筛选查看结果。锁定源轨不能移动，锁定目标不可选。

片段长度、源偏移、循环和源音符属性保留。未指定音色的音符使用目标轨道默认音色，并采用目标混音和 Delay；显式单音符音色保持。原始 MIDI、便携采样及附加消息保留；跨轨清理旧 NoteOff 输出路由，防止音符在新轨起音却从旧轨结束。需要修改被多个片段使用的旧路由源时，先分离当前副本；同轨时间移动保留原路由。

完成移动后选择跟随当前片段，编曲轨道和混音通道同步高亮。打开混音器造成编曲视口变矮时，会重新定位到选中轨道。实时播放无需暂停；已经起音的声音自然结束，后续声音使用目标轨道。

1367 项测试覆盖实际组件回调、核心移动、MIDI 输出与实时信号图。实际界面另完成跨轨、时间吸附、锁定／筛选空白拒绝、隐藏轨下拉、撤销重做、边缘滚动、持续播放与重开，12 份保存结果独立逐项比较完整 ZIP 清单和资源。中途 Esc／失焦与拖动中的目标高亮仍只有组件覆盖；不冒充实际物理取消或游戏声学验收。见[本版记录](verification.md)、[开源参考及取舍](daw-arrangement-reference.md)。

## 已有水平滚动与取消规则

0.1.36 支持拖动时的水平边缘滚动。实际移动后，将指针靠近编曲视口左右边缘，时间轴会继续滚动；越靠近外侧越快，移回中部后停止滚动。片段移动、左右裁剪和参考音频标题对齐均可使用；单纯按下或轻微抖动不会开始滚动。

向右拖出原工程末尾时，画布会按预览临时延展，保留后续操作空间；源音符、工程历史和文件不会按帧修改。松手后只提交最终结果。取消时清除临时范围并停止滚动，已滚到的观察位置会保留在有效范围内。

0.1.35 增加取消保护：按 Esc、切换窗口、焦点离开拖动目标，或系统取消指针捕获时，预览恢复为工程中的状态，不提交这次拖动。锁轨、撤销、重做、打开其他工程、改变源音符或拖动所用的网格、缩放和时间规则，也会使旧拖动失效。正常滚动画面仍按滚动差值计算位置。

参考音频标题采用同样的取消规则。方向键按当前网格移动起点，Home 归零；若正在拖动，先取消鼠标预览，再从工程中的起点执行键盘操作。参考音频仍只参与试听，不混入音乐导出。

取消只丢弃尚未提交的拖动，不撤回中途已经完成的其他编辑。已经成功提交的移动、裁剪和参考音频对齐仍通过撤销恢复。

组件回归覆盖取消、焦点变化、指针归属、同步目标变化以及释放捕获时的重入；使用实际组件源码与捕获工具，界面边界和 React hooks 为隔离替身。边缘滚动另检查按经过时间计算速度、左右边界、视口尺寸变化、延迟帧、静止指针的持续预览、临时范围与源缓存复用。

实际开发浏览器已检查跨屏移动、右裁剪、参考音频左右对齐与一步撤销，保存文件通过独立 ZIP 清单和嵌入资源逐项回读。当前界面工具无法在按住拖动中途插入 Esc 或失焦，因此这些取消路径以及长时间停留仍只由组件/计时工具测试覆盖。最终 Windows 包的历史回读与参考音频输送检查独立记录，见 [0.1.36 验收](verification.md)。
