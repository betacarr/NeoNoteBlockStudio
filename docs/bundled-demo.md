# 内置示例：《欢乐颂》主题

应用首次打开时的“欢乐颂 · 示例”取自 Ludwig van Beethoven（路德维希·范·贝多芬）《第九交响曲》Op.125 第四乐章的主题。作品于 1824 年首演。本示例自行录入开头两个声乐乐句，共八小节，D 大调、4/4 拍；不是整部交响曲。

录谱参考：Mainz: B. Schott's Söhne，无标注日期的 **1826 年初版总谱**，版号 2322，印刷页 113–114（扫描 PDF 第 117–118 页），男中音独唱“Freude, schöner Götterfunken / Tochter aus Elysium / Wir betreten feuertrunken / Himmlische, dein Heiligtum”。已逐音核对旋律与四分、附点四分、八分及二分音符节奏。

- [IMSLP 作品及旧版谱目录（#46254，Public Domain）](https://imslp.org/wiki/Symphony_No.9%2C_Op.125_%28Beethoven%2C_Ludwig_van%29)
- [Wikimedia Commons 保存的同一旧版谱扫描及来源说明](https://commons.wikimedia.org/wiki/File:IMSLP46254-PMLP01607-Symphony_No.9,_Op.125,_Beethoven,_color.pdf)

NeoNBS 简化音符盒编配：旋律整句统一升一个八度至 D4–A4（MIDI 62–69），不对单个音符折返八度；使用竖琴演奏。低音轨采用另写的简单根音、属音伴奏，bell 仅点缀乐句；不使用 chime 或鼓组。速度为方便编辑和播放的 108 BPM，不复刻原管弦乐配器或演奏速度。三条轨道各有一个可编辑片段，共 50 个源音符；片段不强制循环。

只使用旧作的主题，未使用他人 MIDI、录音或现代编曲，也不随应用分发乐谱扫描。所引目录将该旧谱标为公有领域；此说明不表示所有地区或所有相关材料均无权利限制。音符盒采样继续遵循原有许可和权利声明，参见 `THIRD_PARTY_NOTICES.md`。
