# 编曲片段复制、剪切与粘贴

0.1.44 为编曲区增加片段剪贴板。Ctrl / Cmd+C 复制、X 剪切、V 粘贴；钢琴卷帘中的同组快捷键仍操作音符。文本输入框保留普通文字剪贴板行为。

## 粘贴落点

选择目标轨道，把播放头移到所需位置，再粘贴。最早的来源片段对齐吸附后的播放头，最上方来源轨道对齐当前目标轨道。多个片段保留相对拍数与来源工程中的轨道间距，包括中间空行。目标工程的速度、拍号与现有内容保持不变；粘贴不会推开其它片段。

例如来源为 480 PPQ、两片段相差三拍，目标为 960 PPQ，粘贴后仍相差三拍。片段长度、源偏移、循环周期、音符时值和 MIDI 消息起点均按拍数换算，不把 tick 原值直接搬过去。换算后不能合法表示的范围会整体拒绝，不靠压缩间隔或截限改变节奏。

目标下方轨道不够时，在工程尾部补建所需轨道；来源中间空行也有对应位置。新增轨道沿用来源音色、音量、声像、静音、独奏、Delay 和 MIDI 通道，解除编辑锁并清除旧归档轨关联。已有目标轨道的设置保持不变，隐式音符跟随目标音色；显式单音符音色覆盖随片段迁移。

粘贴完成后选中新片段，以最上轨中的首个片段作为主片段。连续粘贴保持同一目标轨道，不会因上次主片段在较低轨道而逐次向下漂移。每次粘贴都创建独立副本，后续编辑互不关联。

## 完整源与资源

片段复制保留完整源，包括裁剪范围之外的音符与 MIDI 消息，因而拉回裁剪边缘仍能恢复内容。音符的力度、音分、声像、高度、释放力度及消息顺序保留；MIDI 消息内部的数据与文本不按 PPQ 改写。跨文档或跨轨道时清理旧 NoteOff 输出轨路由，避免结束事件跑回原轨。

剪贴板只携带所需音色定义和采样。相同资源复用；同 ID 但不同定义或声音数据会创建新身份并重映射引用，不覆盖目标资源。来源工程的原始 MIDI／FLP 归档、参考音频、速度和全局消息不随普通片段复制。现有音符剪贴板的细节见[音符复制](note-clipboard.md)。

剪贴板保存在当前应用会话中，可在打开另一工程后使用，不作为系统剪贴板或其它 DAW 的交换格式。最新成功的音符或片段复制会替换之前的内容；在不匹配的编辑区粘贴会提示切换，不偷偷改动另一编辑区。

## 保护与撤销

复制不改变工程或重做历史，允许从锁定轨道读取；剪切、粘贴遵循轨道锁。选区含隐藏成员时先显示全部所选，避免复制看不见的子集。粘贴不会跳过锁定或隐藏的目标轨道来寻找另一个落点。

剪切先建立完整快照，成功后一次删除所选片段。粘贴把片段、新建轨道及新增资源作为一次编辑提交，一步撤销／重做同时恢复内容和选择。无效数字草稿、失效文档、坏引用或超出工程容量时整体拒绝，保留原工程和旧剪贴板。

与[独立复制](arrangement-groups.md)的区别是落点：独立复制直接放在整组选区右侧，剪贴板粘贴由目标轨道和播放头决定。循环仍是单独模式。

交互参考与本项目的具体选择见[开源 DAW 参考](daw-arrangement-reference.md)。

## 0.1.44 验收范围

1551 项测试（83 个文件）全部通过。实际 CUA 菜单复制／剪切、工具栏粘贴、跨工程换算、补轨、撤销／重做、重复粘贴、副本独立编辑和保存重开，共完成 15 份完整原始 ZIP／JSON 回读。预期由独立夹具给出，不调用产品剪贴板规划器；除保存时间和声明的新 ID 外，工程字段及嵌入资源字节逐项比较。锁轨与错误编辑区的粘贴按钮在界面中保持禁用，拒绝命令本身另由实际 App 回调测试核对。

持续播放中粘贴新音色曾出现“实时试听缺少采样”的错误提示；修复后，已知正在解码的嵌入采样不会被误判为缺失，输送继续推进。修复前后状态与截图保留。项目引用校验另有独立 CPU 对照：一万源／片段及十万规模的检查保持坏引用拒绝规则；这些局部用时不代表界面帧率或跨机器性能保证。两类剪贴板还验证了保存时间戳替换后的精确 64 MiB 边界、超出一字节拒绝及 512 MiB 展开资源保护。

最终 Windows 实包使用真实原生菜单／现有 IPC 完成 23 个编辑历史检查点、7 次音符剪贴板完整回读；迁移工程和默认实时播放工程各完成两次保存／重启回读，后者读到两条真实分轨及总输出电平。它们与浏览器实际控件操作分开记录。

Windows 物理 Ctrl+C／X／V 的额外尝试因 CUA 窗口激活工具不可用而未送达输入，不能计为快捷键验收；浏览器中的复制快捷键探测也未被当作成功。没有系统剪贴板、外部 DAW、扬声器录音、原版游戏声学或 macOS 验收。报告、截图、失败记录与最终包身份见[本版证据](verification.md)。
