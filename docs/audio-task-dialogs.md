# 大分轨拆分器与和弦分析

## 大分轨拆分器

选中音频片段，在编曲区选择「功能 → 大分轨拆分器」，或右键片段选择「处理 → 大分轨拆分器」。选择预置或声部后点击「应用」。预置包含无伴奏合唱、器乐、人声与器乐、人声／乐器／鼓、人声／乐器／鼓／贝斯、完整架子鼓、单个鼓件和分离所有大分轨。切换「单个鼓件」可逐项选底鼓、小军鼓、踏钹、嗵嗵鼓和鼓其他。子混音可合并至少两个未单独提取的声部，菜单也可选择未提取的鼓件。铙钹仍保留在鼓其他残余中。

任务只处理一个片段的可见范围。成功后在原音频轨下创建可折叠的分轨组，按原位置放置各子轨并静音原片段。可在编曲区独奏、移动、复制子轨中的片段，或整体撤销分轨。当前会话中首次成功使用后，片段右键菜单顶部会提供快捷入口。工具栏与文件菜单也可打开拆分器。没有选中音频片段时，应用会提示选文件，并在播放头处创建原片段及分轨组。

在「设置 → 操作与快捷键」可以为八种分轨预置分别绑定按键，默认留空。选中一个音频片段后，按下已绑定的按键可直接运行预置。进度窗口提供取消操作。首次需要下载模型时，由用户确认下载。

## 和弦分析

右键音频或 MIDI 片段，选择「和弦 → 分析和弦」。结果先写入片段，可从同一菜单编辑，或将片段和弦应用到全局和弦轨。打开全局和弦轨后也可直接拖入音频或 MIDI 片段，在其原位置写入和弦。开启局部循环时，拖入只写入片段与循环重叠的范围。可双击全局和弦标签或右键选择「编辑和弦」来校正名称，再把全局和弦应用回所选片段。MIDI 直接按可见音符和时值识别和弦，支持常用三和弦、七和弦和转位。

全局和弦轨标题处的加号在播放头位置按当前吸附设置添加和弦。也可右键空白处选择「创建和弦」，从该小节的强拍开始。新和弦默认一小节，遇到下一个已有和弦时提前结束。导入的 MIDI 有调号时使用当前位置的主和弦，否则使用 C。选中和弦后可按 Delete、选择「编辑 → 删除所选」，或从右键菜单删除。和弦的添加与删除都可撤销，并随工程保存。[Apple 和弦轨操作手册](https://support.apple.com/en-jo/guide/logicpro/lgcpae2172e3/mac)

拖动和弦组上方的标题条可整组移动，按住 Option 拖动可复制到不与原组重叠的位置。拖动标题条的两端可裁剪，重新拉开边缘可恢复原范围。和弦组落在其他组上时，只替换重叠范围。拖动使用当前吸附设置，按 Esc 可取消，完成的操作可一次撤销。裁剪来源随工程保存，重新打开后仍可恢复。[Apple 和弦组操作手册](https://support.apple.com/en-nz/guide/logicpro/lgcp895d79af/12.3/mac/15.6)

文件菜单中的「和弦与速度分析」保留参考音频的试听、固定速度和拍点校正。工程速度只在这个参考音频窗口明确勾选应用时更新。

## 分离模型

分轨使用本机 Mega 模型。六种大分轨由五个模型预测和一个混音残余组成。鼓件使用四个已提供的预测和一个鼓残余。

在同一份 8 秒测试混音上，NeoNBS 和 Logic Pro 的底鼓分别为 5.38 和 15.09 dB SI-SDR，小军鼓分别为 2.02 和 10.49 dB。样本没有嗵嗵鼓，两个嗵嗵鼓轨分别为 −27.82 和 −95.53 dBFS RMS。Logic Pro 同时输出独立铙钹，NeoNBS 将铙钹留在鼓残余中。带人声的 MUSDB18 预览也已对照，人声分别为 18.25 和 19.50 dB，整鼓分别为 6.07 和 17.12 dB。对照以两边的原始分轨文件为准，Logic 的 48 kHz 输出统一重采样到 44.1 kHz 后评分。结果分别保存在 `.local/logic-parity-benchmark/logic-native/parity-ab.json` 和 `soul-ab.json`。

以 Mega 提取的整鼓为输入，LarsNet 的独立铙钹在合成样本上达到 6.87 dB SI-SDR，在两段带话筒串音的实录鼓中为 −17.81 和 −30.74 dB。预训练权重使用 CC BY-NC 4.0，仅用于本机研究。逐项数据位于 `.local/logic-parity-benchmark/kit-research/larsnet/comparison.json`。[LarsNet](https://github.com/polimi-ispl/larsnet)

对 Mega 先去除人声再分鼓，使灵魂乐样本的整鼓得分从 6.07 提高到 10.66 dB，但摇滚和电子样本下降。时频重分配能减少合成样本的嗵嗵鼓串音，但没有找到能在三段样本上稳定改善鼓件的参数。交换立体声通道并反转极性后再次推理，再恢复和平均输出，三个音乐样本的整鼓变化介于 −0.26 和 +0.70 dB。当前产品继续使用单次 Mega 推理。报告位于 `.local/logic-parity-benchmark` 下的 `musdb7/accompaniment-comparison.json`、`kit-research/wiener-comparison.json` 和 `kit-research/tta-comparison.json`。

整鼓的独立候选是原作者发布的 SCNet-large。仅替换 Mega 的整鼓，并重新计算六轨残余后，灵魂乐、摇滚、电子及合成样本的整鼓分别从 6.07、5.61、−3.51、12.38 提高到 16.45、7.41、7.34、13.27 dB SI-SDR。灵魂乐样本中 Logic Pro 为 17.12 dB。四组混音重组的最大采样误差低于 1e−7。28.4 秒拼接样本的 11 秒分块试验也生成了完整的双声道输出，CPU 用时 38.13 秒，峰值内存占用约 10.35 GB。候选仍待验证产品入口与更长的连续实曲。报告保存在 `.local/logic-parity-benchmark/kit-research` 下的 `scnet-hybrid-comparison.json` 和 `scnet-official/streaming-comparison.json`。[作者的权重授权说明](https://github.com/starrytong/SCNet/issues/35)

在相同拼接样本上，6 秒窗口将峰值内存占用降到 6.40 GB，耗时 42.05 秒，整段 SI-SDR 从 8.66 变为 8.69 dB。报告位于同一目录的 `scnet-official/low-streaming-comparison.json`。

参见 [Apple 大分轨拆分器手册](https://support.apple.com/zh-cn/guide/logicpro/lgcp61bae908/mac) 和 [Apple 片段和弦分析手册](https://support.apple.com/en-ie/guide/logicpro/lgcp4993e80c/mac)。
