# 鼓组映射试用

在项目根目录双击 `scripts/start-drum-trial.cmd`，启动当前本地构建。入口会打开独立的四小节鼓组试用工程（16 个源触发、20 个实际子音符），可直接选轨并进入管理器。试用配置独立保存在 `.local/drum-trial/profile`，不使用日常应用配置；不会自动发布或升级安装版。

普通工程可直接点击编曲区的 **＋ 添加鼓组轨道**，或使用 **轨道 → 添加鼓组轨道**。新轨道自动绑定基础预设（MIDI 36 底鼓、38 军鼓、42 闭镲、46 开镲），创建空片段并打开映射管理器。关闭管理器后，主卷帘自动定位触发键音区，可直接绘制源触发。

鼓组源卷帘左侧显示每个触发键自己的自定义映射名称、音名和 MIDI 编号；在管理器的“映射名称”中编辑，应用后所有引用该预设的轨道同步更新。长名称省略显示，悬停可查看完整名称及 GM 参考。旧映射没有名称时显示“未命名映射”，没有映射的行显示“未映射”。行号连续，高号在上、低号在下；不会更改或折叠源触发。“定位已映射”可回到当前预设的触发音区。普通轨以及预设内部的实际子音符卷帘仍显示音高琴键。

推荐键位参考 [MIDI Association 的 General MIDI 页面](https://midi.org/general-midi) 所提供的《General MIDI System Level 1 Specification》Table 3（规范印刷页 6、PDF 第 8 页）。通道 10 是 GM 的打击乐约定，实际打击乐种类由 MIDI note number 区分，不是另一套音高编号。界面名称只是源触发的标准参考；实际声音由子音符映射决定，例如默认开镲使用现有音符盒镲采样近似，可自行编辑。既有映射和旧工程不会被迁移到推荐键位。此次未改变实际子音符的 MIDI 导出通道策略。

已有普通轨道也可在右侧检查器点击 **绑定 / 管理鼓组预设…**；鼓组轨道的入口为 **管理映射预设…**。主编曲继续用钢琴卷帘编辑单个触发事件；预设编辑器中的宽卷帘编辑这个键实际触发的多个子音符。添加轨道是独立的可撤销操作，管理器中“取消”只取消尚未应用的预设编辑，不删除刚添加的轨道。

关闭初次管理器后，选中鼓组轨道，编曲区上方常驻 **编辑鼓组预设** 按钮；旁边显示当前预设名称和引用轨道数。切换回普通轨道时不显示该按钮。重开保存工程后，选中鼓组轨道即可再次进入，不必重新添加轨道。共享预设的修改会影响所有引用轨道；要独立编辑，请在管理器中先复制为独立预设。

也可以直接 **双击鼓组轨道名称或轨道头部** 打开该轨道的预设，单击仍只选轨。静音、独奏、锁定按钮以及主卷帘音符的双击不会触发此入口。普通轨道双击不打开鼓组预设；重命名仍在检查器的 **轨道 → 名称** 中编辑。工具栏按钮保留作为辅助入口。

普通卷帘、鼓组触发卷帘与预设内部实际音符卷帘共用删除反馈：音符短促淡出并收缩，约 160ms。反馈不延后既有删除提交或播放调度，视觉残影不参与命中。恢复同一音符、切换编辑对象或关闭编辑器会清理残影；系统开启“减少动态效果”时跳过持续动画。

1. 新建预设。已有轨道的触发键会按现有音符建立初始映射；空轨提供三个可编辑触发键。
2. 选择触发键，为它填写独立的“映射名称”，在内部卷帘绘制、拖动或调整时值；用下方属性设置乐器、实际 MIDI 音高、延迟拍数和力度倍率。“＋ 子音符”允许同刻、同音高、不同乐器并存。底部明细可准确选择重叠音符。
3. 用“试听触发”或“试听单音”检查实际声音。预设中延迟用四分拍保存，支持精细小数，不依赖工程每拍 tick 数。
4. 取消不改变工程；应用将整个事务写入主工程，可用主工程撤销/重做。窗口内也有独立撤销/重做。

预设嵌入 NBSX。多个轨道选择同一预设时，共享修改；“复制为独立预设”创建新的预设、触发和子音符标识，可单独修改。仍被其他轨道引用的预设不能直接删除。需要恢复普通轨道时选择“关闭映射 · 普通轨道”并应用。

NBSX 保留源触发和预设；主播放、试听、WAV、NBS 和 MIDI 导出使用实际子音符，然后应用一次轨道 Delay。MIDI 按实际乐器分配频道；“另存原始 MIDI”继续保存导入原件。MIDI 格式的整数 tick、NBS 网格及游戏音符盒音域存在限制，导出时应阅读转换提示。缺失触发映射会明确报错，需补全映射或关闭该轨道映射。

旧 NBSX 工程可直接打开，不会自动变成鼓组轨道。本次使用现有 NBSX v2 的可选扩展字段；带鼓组映射的工程需要使用支持该功能的本地构建，旧版应用不能正确播放该扩展。

试用仅涉及鼓组映射，不包含音频分轨、节拍器或轨道分组。音频信号与文件回读检查不能替代扬声器、人耳或游戏录音对照。


普通轨、鼓组触发和预设内部实际音高卷帘都显示原版调音范围：范围内背景正常，范围外更暗。边界与播放共用 `.5` 到 `2` 的采样音高倍率，依据乐器 `rootMidi` 偏移；标准乐器为 MIDI 54–78，两端包含在内。背景只是参考，不移调、不折叠、不禁用范围外编辑；音符、选择和播放头仍画在其上。普通轨按当前轨道乐器、预设内部按当前绘制乐器显示背景；具有单音符音色覆盖或微调的音符，越界提示按该音符自身的乐器及微调判断。

鼓触发行按映射内实际子音符及各自乐器基准判断，绝不把 GM 触发编号当成实际音高：全部在范围内正常显示；全部越界或未映射更暗；部分越界半暗并在左侧显示琥珀色标记，悬停解释具体状态。该背景参考映射默认音高；源触发自身的音高微调仍是独立参数。公开构建当前仅启用经典主题，未为本次检查启用内部 Liquid Glass 主题。
