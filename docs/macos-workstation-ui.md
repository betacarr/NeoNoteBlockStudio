# macOS 工作区第一轮优化（2026-11-08）

## 参照和边界

检查了本机 Logic Pro Creator Studio 的实际轨道窗口、辅助功能树和截图：顶部传输与 LCD、左侧资源浏览、中央轨道、下方可切换编辑器。未改动 Logic 工程、未提取其图标或美术资源。本轮是 NeoNBS 的工作流映射，并非已完整复刻 Logic 的全部面板/功能。

## 已实现

- 检查器移动到编曲区左侧，资源库与属性区紧邻，视觉与键盘 Tab 顺序一致。
- 紧凑控制栏、分区 LCD 和系统字体；提高轨道/编辑区可用空间。
- 新增“编曲 / 分屏 / 钢琴卷帘”工作区切换。切换不卸载编辑器、不修改工程；单区模式同步当前编辑焦点，原有分屏拖拽保留。
- 窄窗口收紧侧栏宽度与控件间距；原有资源库、检查器和混音器开关保留。
- 原有音符盒图标、音色和编辑语义保留。样式集中于 `src/ui/Workstation.css`。

## 验证

- `tests/editor-panel-focus.test.ts`：新增反复切换模式与焦点回归。
- `node scripts/smoke-workstation-layout.mjs`：Electron 实际验证三种模式、重复切换、文档不变、侧栏/混音器、1440×900 与 1100×760，及无 renderer 异常。
- 窗口现有最小宽度为 1050；未为测试改变该约束。
- 截图与测试记录在 `.local/workstation-layout/`（不进入版本库）。

## 后续范围

目前工作区模式为会话内状态；原有分屏比例仍按原逻辑保存。Logic 的通道条式检查器、完整轨道头组件重构、工具菜单等未冒充本轮已完成。后续应使用真实复杂工程验证，再逐步扩展而非直接替换所有交互。
