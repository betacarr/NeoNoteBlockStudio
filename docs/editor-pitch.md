# 编辑试听音高

0.1.41 起，默认实时播放、钢琴键与单音试听、带 Delay 的试听，以及 Web WAV 导出都使用音符的实际音高。超出原版 F♯3～F♯5（MIDI 54～78）的音符仍可播放，保留半音间隔和音分微调，不执行原版音高截限、旧版传输量化或高音回绕。

采样播放倍率按 `2 ** ((音符 MIDI − 采样基准 MIDI + 音分 / 100) / 12)` 计算，再乘声音事件自身的音高倍率；自定义采样沿用自己的基准音。距离衰减、声像、音量与资源选择继续采用工程设置。低音减速后会自然延长采样尾音，显示时值不会将它截断。

检查器和工程诊断仍提示超出原版音域，以及在游戏内需要资源包或模组支持。此提示不会改写源音符。MIDI、NBSX 和 NBS 转换各自原有的音高保存范围不变。

「设置 → 声音与资源 → 试听方式（本机）→ 原生离线对照」继续用于核对目标游戏，保留目标版本的音高限制与传输规则。WAV 导出默认勾选原生混音；要导出编辑器中的完整音域，请取消「使用已加载版本的原生 OpenAL 离线混音」。导出面板会说明两者的区别。

## 验证范围

17 项新增测试覆盖 MIDI 0、53、54、66、78、79、100、127，音分、自定义基准、声音事件倍率、旧版高音回绕、实时混音刷新、Delay 与低音尾长；原生请求仍按原规则生成。

实际界面载入含便携 440Hz 合成采样的四音工程，通过真实 Web 音频引擎导出 WAV。独立 FFT 得到约 207.652348、932.327562、440.000000、3135.963591Hz，均与预期相符；低音在显示时值结束后仍有自然尾音。这验证编辑器的变调，没有新增游戏录音或硬件声学验收。[本版记录](verification.md)。
