## Source and artifact provenance

- Official [Mojang version manifest](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json): 164 artifacts (103 formal releases and 61 historical clients) cached, SHA-1 checked and audio bytecode indexed. Snapshots and prereleases are excluded. Most historical clients have not received behaviour review.
- 44 releases from 1.14.4 through 26.3 have generated source comparisons for selected audio classes. The registry records original client/mapping hashes and source hashes. Checked core invariants are linear distance attenuation with reference distance 0, rolloff 1, note-block volume 3, two-octave pitch formula, pitch clamp 0.5–2 and Java float-to-PCM16 conversion.
- The source comparison separates STB from the JOrbis implementation introduced in 1.20.5, HRTF configuration availability, and the later category-volume calculation. It does not prove all code paths or device defaults equivalent.
- 34 official asset indexes and their sound definitions inspected. The loader now resolves actual note-block sound events. Similar filenames do not identify the played sample: modern harp uses `note/harp2`, bass uses `note/bassattack`.
- Native STB bindings checked against LWJGL generated C for [3.2.2](https://raw.githubusercontent.com/LWJGL/lwjgl3/3.2.2/modules/lwjgl/stb/src/generated/c/org_lwjgl_stb_STBVorbis.c) and [3.3.1](https://raw.githubusercontent.com/LWJGL/lwjgl3/3.3.1/modules/lwjgl/stb/src/generated/c/org_lwjgl_stb_STBVorbis.c). The primitive pointer JNI overloads ignore the environment/class slots; Java array overloads are not called directly.

The other four remain code-reviewed with no inherited world recordings.
