# 轨道整理

从 0.1.48 起，检查器「轨道」区提供上移、下移与删除；顶部「轨道」菜单提供相同操作和添加轨道。

- 上移／下移与相邻的**可见轨道**交换位置。乐器筛选不会改变，隐藏轨道保留原来的位置；编曲区和混音器使用同一顺序。
- 删除只作用于当前轨道及其片段。其它轨道仍在使用的共享源保留；只清理由本次删除失去全部引用的源。锁定轨道可调整顺序，删除前须解锁。
- 排序、删除均一步撤销／重做，恢复工程和原选择。删除后优先保留存活的片段选区，否则选最近的可见轨道；筛选没有剩余结果时保留筛选并提示显示当前轨道。
- 最后一条轨道也可以删除；空工程可添加轨道或粘贴片段继续编辑。普通 Delete／Backspace 仍按当前编辑区删除音符或片段。轨道操作默认不分配快捷键，可在偏好设置中自行配置。

整理轨道不会移动音符的音乐位置，也不会修改音色、混音、Delay、原始 MIDI 或便携采样。对未指定 MIDI 通道的旧轨道，在顺序改变会影响导出通道时记录原通道，避免重排引起音色／控制消息错配。再次手动移回原位置仍保留这项明确通道记录；撤销则恢复完整旧状态。新增轨道优先选择未使用的 MIDI 通道，16 个通道全占用时允许复用。

隐藏、过期和无效目标会拒绝操作，排序／删除的保存容量在提交前检查。实时试听不因整理操作主动停止；删除后的轨道不再发声。删掉最长轨道导致工程结束位置缩短时，播放仍可能自然结束。

开源依据见 [DAW 交互参考](daw-arrangement-reference.md)，验收见 [0.1.48 记录](verification.md)。
