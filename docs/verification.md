# Windows 0.1.57 发布验证

本页记录可下载版本的检查范围，面向使用者说明哪些内容已验证。

- 单元与组件测试：103 个测试文件通过，2025 项通过、1 项因缺少私人语料跳过；覆盖工程读写、编辑、撤销、MIDI／NBS 互通、混音和效果事件。
- Windows 安装版已实际安装并确认版本、程序启动、默认播放、诊断包导出及程序内容一致。卸载检查通过，未要求删除用户数据。同一生产构建的 MIDI 导入／导出与工程重开检查跨两次进程会话完成五次工程压缩包读回，原始 MIDI 导出逐字节一致。
- 文件工作流已检查启动时打开工程、向已有窗口转交工程、恢复内容保存清理、取消关闭及保存后关闭。
- Windows 便携版已从发布 EXE 实际启动并打开示例工程；安装版与便携版的实际程序内容均与受检生产构建一致。下载页提供 SHA-256 校验值。
- 分发检查通过：程序版本与必要许可齐全，不含源码映射、开发目录路径、私人工程、游戏贴图和客户端文件。音频文件仅允许默认采样清单中的 20 项，并逐一核对哈希与来源说明。
- 缺少资源回归：受控返回空游戏实例列表、阻止 HTTP(S)、拒绝游戏资源加载和原生渲染请求。旧版 0.1.55 在该场景报缺少采样；0.1.57 的实际生产程序加载 20 种不同乐器，20 条对应轨道与总输出均测得非零电平；安装后程序也通过默认播放和日志导出检查。该检查证明软件音频链路产生信号，不代表特定用户的扬声器、系统音量或设备已经验证。
- 诊断导出通过实际主程序菜单处理链路，控制文件选择器结果完成正常导出、两阶段取消、界面崩溃后导出和日志目录不可写时的内存导出。检查导出包及原始日志，测试中的个人路径、文件名、工程标题与描述均未出现。
- 便携版通过实际帮助菜单和保存对话框导出 ZIP，确认包含版本、20 种采样状态、真实播放输出记录和导出时的已停止状态；实际程序内容与受检生产构建一致。
- 日志单元测试覆盖字段白名单、错误脱敏、文件轮换、过期记录、并发读写、限流与独立异常记录。导出包不包含工程、音符事件、采样或环境变量，测试不代表能够识别任意错误文本中的所有个人信息。

当前 Windows 安装包未做数字签名。声音处理有版本与设备边界，数学测试和同库比对不代表所有游戏场景等价。macOS 尚未完成同等实际验收。
