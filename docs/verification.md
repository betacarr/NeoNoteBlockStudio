# 发布验证

## 0.1.59 合并版本

Windows 分发包在独立干净目录基于 `a70e2b6` 重建，包含“不保存退出”修复；Mac 应用基于 `f995c19`，验收脚本为 `4fa675c`。已逐项核对两者的应用构建输入相同，后续仅修改验收脚本和发布文档。两平台来源及分发文件哈希分别记录在 `windows-verification.json` 和 `macos-verification.json`；完整附件校验值见 `SHA256SUMS.txt`。

- 合并后的单元与组件测试：105 个测试文件通过，2036 项通过，1 项因缺少私人语料跳过；类型检查和生产构建通过。
- Windows x64 安装版／便携版重新构建，分发检查逐一验证官方采样与来源说明，不含私人工程、开发路径、源码映射和游戏客户端。
- 实际 Windows 程序在断网、禁止游戏资源与原生渲染的条件下，20 条乐器轨道与总输出均有信号；工程启动／二次打开、恢复保存、取消关闭和保存后关闭通过。
- 合并后的主程序帮助菜单通过正常导出、两阶段取消、渲染界面崩溃后导出及日志目录不可写时的内存导出检查，诊断包记录新的官方采样库标识。
- Windows 安装版实际安装、核对程序内容、默认播放、日志导出和卸载检查通过；本次检查使用独立目录，保留日常用户数据。
- Windows 安装副本通过取消退出、放弃修改退出及保存关闭；放弃退出不弹保存选择器，原保存文件逐字节不变。便携版从实际 EXE 启动，核对程序内容、20 种默认音色、片段独立复制／撤销及工程保存。
- Windows 完整曲目工作流完成 11 组检查、8 段软件音频采集和 WAV／NBS／MIDI 三种导出。官方示例保留 5838 个 NBS 音符，MIDI 逐项匹配 5304 个可发声音符；534 个零力度音符按 MIDI 规则不计作发声事件，仍保存在 NBSX／NBS 中。
- 通用工作流验收脚本按系统选择 Ctrl 或 Command，不再将 Mac 按键用于 Windows；保存文件与独立导出读回断言保持。该修正不改变应用或两平台受检安装包。
- 2026-10-27，macOS 27.0.1、Apple Silicon：0.1.59 的 arm64 与 x64 DMG 均挂载为只读映像，将程序复制到隔离安装目录并推出映像后实际运行；内容与受审构建一致，代码签名完整性和 ZIP CRC 检查通过。
- 两架构均通过窗口关闭／重开、Command 操作、LaunchServices 文件打开、20 种默认音色软件电平、诊断导出（包括渲染崩溃及日志目录不可写）、工程恢复、取消／放弃／保存退出、MIDI／NBS 读写检查。Intel x64 在 Apple Silicon 上通过 Rosetta 运行，未在物理 Intel Mac 上验收。
- Mac 分发包的 `macos-verification.json` 记录应用源码 `f995c19`、验收脚本 `4fa675c`、14 项双架构检查及四个分发文件的 SHA-256。摘要 `sourceCommit` 指向验收时的 HEAD；应用构建输入仍与 `f995c19` 一致。真实音频设备、硬件 MIDI、物理 Intel Mac 和全部最低系统版本兼容性不在本次验收范围。
- 两处验收脚本修正保留原断言：异步发起窗口关闭后等待关闭事件，并在播放前开始观察短暂音量峰值；没有修改应用代码或放宽通过条件。
- harp 译名调整、NBS 相邻同乐器层合轨及其他 FL MIDI 通道映射属于后续工作，不包含在 0.1.59 中。

下方保留此前各版本实际验收范围，不能代替新构建的验收。

- 实时试听使用独立测试工程内嵌的原创合成 WAV，检查解码、播放位置推进和暂停。检查了原生桥接组件加载及调用系统库；没有把这些结果当作 Minecraft 原生声音验收。

## Windows 0.1.58（历史验收）

本页记录可下载版本的检查范围，面向使用者说明哪些内容已验证。

- 单元与组件测试：103 个测试文件通过，2029 项通过、1 项因缺少私人语料跳过；覆盖工程读写、编辑、撤销、MIDI／NBS 互通、混音和效果事件。
- 20 种默认采样逐一匹配官方 Java 26.3 的声音事件、资源路径、字节长度和 SHA-1／SHA-256；版本元数据、索引和声音定义也分别校验。解码前使用原始字节，保留各采样振幅，不做响度归一化或音量补偿。
- 使用相同 FFmpeg 解码设置比较上一版 OpenNBS 采样与官方文件，旧钢琴文件峰值约低 4.24 dB，方波约低 2.29 dB。该结果是单文件 PCM 峰值比较，不代表感知响度或游戏整条输出链路一致。
- Windows 安装版已实际安装并确认版本、程序启动、默认播放、诊断包导出及程序内容一致。卸载检查通过，未要求删除用户数据。下载页提供安装版、便携版与 SHA-256 校验值。
- 分发检查通过：程序版本与必要许可齐全，不含源码映射、开发目录路径、私人工程、游戏贴图和客户端文件。音频文件仅允许默认采样清单中的 20 项，并逐一核对哈希与来源说明。
- 缺少资源回归：受控返回空游戏实例列表、阻止 HTTP(S)、拒绝游戏资源加载和原生渲染请求。旧版 0.1.55 在该场景报缺少采样；0.1.58 的实际生产程序加载 20 种不同乐器，20 条对应轨道与总输出均测得非零电平；安装后程序也通过默认播放和日志导出检查。该检查证明软件音频链路产生信号，不代表特定用户的扬声器、系统音量或设备已经验证。
- 诊断导出通过实际主程序菜单处理链路，控制文件选择器结果完成正常导出、两阶段取消、界面崩溃后导出和日志目录不可写时的内存导出。检查导出包及原始日志，测试中的个人路径、文件名、工程标题与描述均未出现。
- 日志单元测试覆盖字段白名单、错误脱敏、文件轮换、过期记录、并发读写、限流与独立异常记录。导出包不包含工程、音符事件、采样或环境变量，测试不代表能够识别任意错误文本中的所有个人信息。

0.1.57 曾完成 MIDI 原始字节导出、五次工程读回、启动／二次打开、恢复与关闭保存，以及便携版真实菜单导出检查；这些既有工作流本版未修改，上述历史验收不计为 0.1.58 的新实测。

当前 Windows 安装包未做数字签名。声音处理有版本与设备边界，数学测试和同库比对不代表所有游戏场景等价。macOS 尚未完成同等实际验收。
