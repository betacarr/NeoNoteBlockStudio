# 发布验证

## macOS 0.1.56

2026-10-27 在 Apple Silicon Mac、macOS 27.0.1 上检查。最低系统要求为 macOS 13：按 Electron 实际二进制的最低系统版本核对，不以打包配置文字代替运行时要求。

- 单元与组件测试：101 个测试文件通过，1999 项通过、1 项因缺少私人语料跳过；类型检查与生产构建通过。
- Apple Silicon arm64 的实际 DMG 已挂载、复制到独立安装目录并启动。检查了原生设置菜单、Command 全选／独立复制／撤销、物理 Control 隔离、取消退出和取消保存、保存退出、关闭最后窗口后重开，以及经 LaunchServices 打开工程。
- Intel x64 DMG 同样挂载并复制安装，在 Apple Silicon 上经 Rosetta 通过上述 macOS 工作流、原生桥接、MIDI 保存重开及工程恢复／单实例转交检查；没有将 Rosetta 结果当作物理 Intel Mac 验收。
- 实时试听使用独立测试工程内嵌的原创合成 WAV，检查解码、播放位置推进和暂停。检查了原生桥接组件加载及调用系统库；没有把这些结果当作 Minecraft 原生声音验收。
- 打包程序完成 MIDI 导入、编辑、撤销／重做、保存与重开；跨两次进程会话完成五次工程压缩包读回，原始 MIDI 导出逐字节一致。工程恢复、单实例转交、取消关闭和保存后关闭通过。
- 两个架构的 DMG／ZIP 均检查程序版本、NBSX 关联、最低系统要求、ICNS 图标、Electron／Chromium 与第三方许可、Java 适配器、主程序／桥接组件架构，以及 ad-hoc 代码签名完整性。
- 两个 ZIP 通过完整 CRC、可执行权限和内部程序／工程代码／桥接组件与受检构建的一致性检查；提供四个分发文件的 SHA-256 校验值。
- 分发内容扫描不含源码映射、开发目录路径、私人工程、未公开功能或 Minecraft 游戏素材；源码发布检查通过。

完整曲目的预览、真实音频输出、静音／音量、循环、编辑与 NBS／MIDI／WAV 导出等补充结果见 [常用功能验收](common-workflow-verification.md)。

未进行 Apple Developer ID 签名和公证。物理 Intel Mac、macOS 13～26、硬件音频／MIDI、Minecraft 原生库及游戏录音一致性不在本次实机验收范围。macOS 安装与构建见 [macOS 说明](macos.md)。

## Windows 0.1.55

本页记录可下载版本的检查范围，面向使用者说明哪些内容已验证。

- 单元与组件测试：100 个测试文件通过，1996 项通过、1 项因缺少私人语料跳过；覆盖工程读写、编辑、撤销、MIDI／NBS 互通、混音和效果事件。
- Windows 安装版已实际安装并确认版本、程序启动和 NBSX 文件关联。安装后运行 MIDI 导入／导出与工程重开检查，跨两次进程会话完成五次工程压缩包读回，原始 MIDI 导出逐字节一致。卸载检查通过，未要求删除用户数据。
- 文件工作流已检查启动时打开工程、向已有窗口转交工程、恢复内容保存清理、取消关闭及保存后关闭。
- Windows 便携版已从发布 EXE 实际启动并打开示例工程；安装版与便携版的实际程序内容均与受检生产构建一致。下载页提供 SHA-256 校验值。
- 分发检查通过：程序版本与必要许可齐全，不含源码映射、开发目录路径、私人工程或 Minecraft 原版声音、贴图和游戏文件。

当前 Windows 安装包未做数字签名。声音处理有版本与设备边界，数学测试和同库比对不代表所有游戏场景等价。0.1.56 的 macOS 工作不代表在本机重新完成 Windows 安装验收。
