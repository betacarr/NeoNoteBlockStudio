# 当前状态

当前源码版本为 **0.1.54**。本版关闭 Liquid Glass 公开入口并隔离旧偏好；实现仅供内测。首次公开源码版本为 0.1.53，基于内部 0.1.52 的编辑功能。仓库名为 NeoNoteBlockStudio，软件简称 NeoNBS，采用限制编辑器收费、允许用户作品盈利的自定义许可。

编辑功能包括 MIDI／NBS 互通、FLP 音符与片段导入、独立 NBSX 工程、可调整编曲／钢琴面板、横向与纵向缩放、轨道整理、片段拆分与剪贴板、力度与声像、实时混音与电平、派生 Delay。

首次公开时已加入发布文件边界、提交身份检查、素材与第三方许可说明、干净历史准备，以及改名后的旧资料目录兼容。原应用标识与工程扩展名保留，显式测试资料目录优先，已有旧资料不会因改名直接失去入口。

本次测试和构建结果以 [验证说明](verification.md) 为准。CHANGELOG 中更早的测试数量和人工操作是对应内部版本的历史记录。原始研究报告涉及本机路径、私人测试或反编译摘录，不随公开源码发布。

声音研究没有覆盖所有游戏版本与设备，实时试听与游戏原生声音仍可能不同；宏大声音矩阵和游戏内结构生成不作为当前交付前提。macOS 尚无实际运行验收。
