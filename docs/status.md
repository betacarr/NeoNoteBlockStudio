# 当前版本与支持范围

当前分支版本为 **NeoNBS 0.1.56**，增加 macOS Apple Silicon／Intel 的 DMG 与 ZIP 构建。已发布的 Windows x64 安装版与便携版为 0.1.55。[查看已发布版本](https://github.com/betacarr/NeoNoteBlockStudio/releases/latest)。

现有功能包括 MIDI／NBS 互通、支持范围内的 FLP 音符与片段导入、独立 NBSX 工程、编曲与钢琴卷帘、双轴缩放、片段拆分与剪贴板、力度与声像、实时混音和派生 Delay。

声音资源由使用者从自己的 Minecraft 安装中读取。实时试听与原版处理仍可能存在差异；原生声音对照有版本与设备边界。游戏内结构生成尚未提供。

Windows x64 与 macOS 分别记录实际验收范围，macOS 安装见 [macOS 说明](macos.md)。操作见 [图文上手](quick-start.md)，具体检查范围见 [发布验证](verification.md)。
