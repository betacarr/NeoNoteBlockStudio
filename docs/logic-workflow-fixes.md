# Logic 操作准则：编辑与工程安全

本轮修复围绕工程切换、编辑事务、片段目标与试听导航。界面布局、音符盒音域提示、鼓组映射、CPU 默认与实验 GPU 选项保持原有方向。

## 工程切换与输入

- 打开／拖入候选工程先完成解析及校验。无效文件不会要求放弃当前工程，也不会清理其恢复副本。
- 当前工程有修改时，新建／打开／FLP 导入使用“保存并继续／不保存／取消”。保存取消或失败停留在当前工程；只有成功切换后才清理旧工程的对应恢复副本。
- BPM、名称、说明等先编辑草稿，Enter 或离开输入框提交一次，Esc 取消。多行说明使用 Ctrl/Cmd+Enter 提交。滑杆一次拖动只产生一次工程撤销；中间值用于预听。
- 通用模态窗口接管焦点，Tab 在窗口内循环，底层内容 inert；关闭后恢复原焦点。原有全局 Space 播放偏好保留，工程切换确认及采样替换窗口阻止底层启动播放。
- 音频与工程拖入按文件类型分流；音频保留鼠标位置及目标音频轨。工程文件一次一个；混合文件批次明确拒绝，不进行部分导入。桌面原生拖入 NBSX 会登记同名资源目录。

## 目标与片段

- “替换轨道默认音色采样”和“替换所选音符的采样”是不同目标。窗口显示准确乐器及工程内轨道、音符覆盖、鼓组子音符引用数。
- 默认选择创建独立音色，只路由指定目标；全工程共享替换需要明确点击对应按钮。采样先解码校验，再原子提交。局部音符替换会按需分离共享源。撤销／重做同步恢复实际声音缓存。
- Logic 预设右键音符或 MIDI 片段打开上下文菜单；Alt/Option 拖动创建独立副本，显示副本预览并保留原件。FL/NBS 右键擦除和原有操作预设继续可用。
- 音频片段有单独高亮，支持 Shift 多选、Delete、复制／剪切／粘贴及撤销／重做。音频和音符片段分别成组选择；全选菜单明确显示目标类型，防止混合对象的模糊编辑。
- 音频剪贴板支持当前打开工程内的普通音频轨。关闭／重新打开工程或切换工程后不复用托管音频权限；需要重新导入或从当前工程复制。音频资源可安全复用，片段位置与静音独立。

## 播放与循环

- 播放中点击或拖动标尺保持播放；暂停中定位保持暂停。快速连续定位只采用最后一次，不叠加旧声音。
- 编曲标尺上方 10px 拖动设置局部循环，下方定位。范围按当前网格吸附，至少保留 1 tick；Esc、失焦及目标失效取消未提交手势。
- “循环所选”按当前所选音频或音符片段的完整跨度设置范围。“局部循环”切换该范围，“整曲循环”使用完整工程。
- 局部范围使用 `[start, end)`，以工程 tick 保存为可选 `Project.cycle = { start, end, enabled }`。旧工程无此字段时行为不变；重新打开恢复局部范围及启用状态。撤销／重做范围时由单一输送更新路径重排声音。
- 范围外启动或 seek 会归到局部循环左端；“停止并回到起点”始终停止并显示工程起点，保留循环范围；下一次播放从有效循环位置开始。实时音频、参考轨与音符使用同一时钟，原生离线对照使用 WAV 中对应范围。
- 含外部音频的保存反馈明确提示同名 `.assets` 目录，移动工程时需一起移动。

## 验证入口

`node scripts/smoke-logic-workflows.mjs` 使用独立配置、隐藏窗口与生成的测试工程／音频，验证原错误与修复后的完整 UI、主进程及磁盘保存路径。结果、保存工程与截图写入 `.local/logic-workflows/run-*/`。不使用用户原工程、私有音频或模型下载。
