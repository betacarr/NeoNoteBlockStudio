# 编辑器贯通验收（0.1.51）

本轮以现有编辑需求收尾：沿用 Ardour、Qtractor、Logic 的既有源码／操作研究，核对导入、选择、编辑、撤销、保存重开和导出。没有继续扩大声音版本矩阵或结构生成范围。24 项需求的只读审计保留在 `.local/editor-workflow-audit/requirements.json`；其中旧版实际界面、当前组件回调与当前实包证据分别标明，没有把历史记录当作本次重跑。

审计查明并修复了两处问题：

- 检查器的力度／声像滑块原来每次变值都写历史。真实旧版将力度从 50% 拖到 89%，一次撤销只回到 84%。现在拖动只更新临时试听，松手经统一检查提交一次；一步撤销恢复原来的各音符值。检查器仍是统一绝对设置，钢琴力度区仍是保留动态的相对拖动。
- MIDI 出口还按源头至片段末尾的全部循环数拒绝工程。合法的大偏移短片段即使只有一个起音，也会失败。现在只计算实际落入范围的附加消息周期，保留循环接缝顺序和末端释放；400 万附加消息上限在复制前检查，空周期不会逐个遍历。

滑块沿用现有混音器的预览／提交职责，独立实现数字草稿、工程身份、选择和捕获失效保护。无效数字会保留并阻止原生移焦及该次残余变更；有效草稿与随后拖动分别形成可撤销操作。键盘方向键继续按步调整。临时预览不写母版或清空重做，取消时恢复当前工程。实时预览更新后续发声；已起音的采样自然尾音不变。

## 当前实际流程

1973 项测试（97 文件）、类型检查和生产构建通过。真实界面使用独立窗口加载这一构建，未直接操作用户的已有标签页。

| 输入／操作 | 本次独立核对 |
| --- | --- |
| 综合 MIDI：两条发声音轨、变速／变拍、CC、弯音、SysEx、音色切换、释放力度与超音域 | 16 份完整 NBSX 读回：导入重开、两滑块拖动／撤销／重做、无效草稿取消、有效草稿后首个拖动及两步撤销、编辑／重开／导出前后。除根 modifiedAt 外全 JSON、ID、ZIP 清单与资源字节一致。 |
| 可见文件菜单的「另存原始 MIDI」 | 与手工编码的 225 字节输入完全一致。 |
| 标准 MIDI 导出面板 | Mido 1.3.3 独立核对全部三条 SMF 轨的有序绝对事件；编辑后仅指定音符力度改变。两次导出均为 5 个原音符，保留时值、释放及原附加消息。 |
| 同一短曲的每拍 8／12 格 NBS，加入 Delay 前后各一次 | 四份实际下载与预先固定的字面答案、原始格式读取及独立 nbs.js 读取一致。5 个原音符变为 11 个可听事件，另有 2 个专用速度事件；源工程仍为 5 音符。 |

| 真实 FLP 夹具：映射确认、导入、轨道改名／撤销、保存重开、当前 8 格 NBS 导出 | 5 份完整 NBSX 读回；旧 Python 原始解析结果独立核对 6 轨、3095 源音符和 884 实际起音，NBS 全部 884 事件匹配。原 FLP 字节保持。 |
| MIDI 出口修复后的既有语料 | 24 份输入由 Mido 独立复核，完整往返通过；没有重写旧报告。 |

综合 MIDI 的主音量保留导入默认 0.7，轨道音量为 1；主音量是试听设置，不参与本次 NBS 字面力度答案。原夹具说明中的 master=1 已在独立补充说明中纠正。NBS 的 88 键截取、整数力度／微调、变速播放器兼容性仍会提示；这里不宣称任意 MIDI 能无损写入 NBS。

Windows 最终包的菜单、保存和进程重启结果，以及文件身份见 [0.1.51 验收清单](verification.md)。浏览器实际鼠标操作与桌面菜单／IPC 检查分别记录；受控文件窗口返回不冒充人工操作系统文件窗口。

## 保留的验收范围

本次界面布局在 1280 像素视口检查，滑轨和读数均在检查器字段内；窄视口保护另经 CSS 审查，没有声称所有屏幕尺寸都实测。两次因输入框自动滚动而误用旧坐标的验收操作未作为通过证据，重新定位后才进行有效草稿／声像测试；最终文件对比未出现额外修改。

没有新增声学／PCM 对比、原版游戏录音、外部 OpenNBS 运行、硬件 MIDI 或 macOS 验收。原生物理组合键、持有指针时的取消／撤销等未测组合仍保留原来的组件或历史证据范围。声音矩阵与结构生成继续按用户决定延后，不能从编辑器流程通过推断它们完成。
