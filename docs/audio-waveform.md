# 音频轨道波形

波形来自播放使用的 Web Audio 解码 PCM，不修改原音频，不自动转音符。

此前片段只在整段音频中固定取 256 个峰值单点：既跳过短瞬态，又在缩放时拉伸固定数量的线。原缓存只保存绝对峰值，绘图上下对称，无法表达实际正负包络。

现在保存所有声道合并的有符号最小/最大包络（声道不平均，反相不会抵消），基准约每 128 帧一个桶，至多 1,048,576 桶；更粗层级成对保留极值。绘图按每个可见 CSS 像素对应的完整音频时间范围取极值，包含片段源偏移、工程变速、位置与可见滚动区。不会对片段自动归一化。静音显示零线，读取中明确提示，资源变化先清除旧显示。

这是多声道联合峰值包络，不是分声道显示或逐样本编辑器。基准桶会让极短瞬态在高倍率下有约一个桶宽的保守展宽；不会将瞬态漏掉。长音频绘图工作按可见宽度限制，层级缓存在解码时一次生成，未写入 NBSX，重开时从源音频重建。

`tests/audio-waveform.test.ts` 验证静音、单帧瞬态、有符号不对称、反相及右声道音频、奇数分级尾帧、片段源偏移、变速和滚动。

`scripts/smoke-audio-waveform.mjs` 使用隔离桌面实例，检查上述可见包络、已存在的 CC BY 真实音乐、放大、滚动、重新打开及拖入导入。真实音乐仅从原文件读取作为本地 QA 输入，不随产品打包。运行前需已有 `.local/effect-eval/slow-motion-dream-ccby3.wav`。
