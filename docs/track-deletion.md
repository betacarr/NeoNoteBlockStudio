# 删除轨道

轨道列表顶部有常驻“删除”按钮，作用于高亮轨道；右键任意轨道头也能打开带轨道名称的菜单。普通音符轨、鼓组轨、音频轨、分轨子轨都可直接删除。分轨组菜单明确写出“删除分轨组及 N 条子轨”，同时删除全部子轨及片段；有锁定子轨时整组拒绝删除，不发生部分删除。

轨道头/名称按钮具有键盘焦点时，Delete 或 Backspace 删除该轨道；Shift+F10 打开同一菜单，方向键移动，Escape 关闭并返回轨道。自定义“删除轨道”快捷键也仅在轨道头/名称按钮焦点下生效。钢琴卷帘、片段、输入框继续使用各自删除语义；按住删除键不会连续删除相邻轨道。

删除是一个可撤销事务，恢复轨道、内容、混音状态、鼓组预置引用、父子关系与音频资源引用。共享预置、音色定义、工程资产和磁盘音频不随删轨自动清除。最后一条轨道可以删除，留下空编曲区，并可通过“添加轨道”或撤销继续工作。不额外弹确认框。

播放中删组时停止被删除的音频源，保留其他轨道播放；删空播放内容时停止传输并同步播放按钮，防止旧声音/状态悬挂。参考音频仍存在时保持其独立播放逻辑。

此前底层已有删除及撤销，但轨道头缺少统一入口，音频头还错误地打开片段菜单。此次还修复了右键聚焦触发自动滚动、进而误命中邻轨的风险：右键目标在滚动前确定，并显式传递轨道 ID；菜单在工程变化时失效。

验证：`scripts/smoke-track-delete.mjs` 用隔离隐藏实例检查全部轨道类型、组、锁定、键盘和输入框、实际播放输出、撤销/重做、最后轨道、保存重开及原音频字节保持不变。`tests/app-track-management.test.ts` 使用真实 App 回调和历史栈验证整组恢复；`tests/track-delete-audio.test.ts` 验证纯模型层的组原子性与资源保留。现场平台为 Windows Electron。
